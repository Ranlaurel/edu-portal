# Семья: слова по теме

## Слова по теме

| Английский | Перевод |
|---|---|
| parent | родитель |
| mother / mum | мама |
| father / dad | папа |
| brother | брат |
| sister | сестра |
| grandmother / granny | бабушка |
| grandfather / grandpa | дедушка |
| son | сын |
| daughter | дочь |
| relative | родственник |
| birthday | день рождения |
| holiday | праздник |
| celebrate | праздновать |
| guest | гость |
| present / gift | подарок |

## Примеры предложений

- My **parents** work a lot. (Мои родители много работают.)
- I have one **brother** and one **sister**. (У меня есть брат и сестра.)
- We invite a lot of **guests** on holidays. (Мы приглашаем много гостей на праздники.)
- My **relatives** live in different cities. (Мои родственники живут в разных городах.)

## Мини-практика

1. Переведи слово relative — **родственник**.
2. Как будет «гости» на английском? — **guests**.
3. Переведи слово celebrate — **праздновать**.
4. Как по-английски «дедушка»? — **grandfather / grandpa**.
5. Переведи предложение: I have two sisters and one brother. — **У меня две сестры и один брат.**
