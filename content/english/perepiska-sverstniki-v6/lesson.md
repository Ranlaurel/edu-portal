# Переписка с зарубежными сверстниками — слова

## Слова по теме

| Английский | Перевод |
|---|---|
| pen friend / pen pal | друг по переписке |
| letter | письмо |
| Dear... | Дорогой/Дорогая... (обращение в письме) |
| Best wishes | С наилучшими пожеланиями |
| Love | С любовью (в конце письма) |
| I'm writing to tell you | Я пишу, чтобы рассказать тебе |
| How are you? | Как ты? |
| Write back soon | Напиши в ответ скорее |
| country | страна |
| hobby | хобби |
| favourite | любимый |
| at the moment | сейчас, в данный момент |
| right now | прямо сейчас |
| reply | отвечать (на письмо) |
| address | адрес |

## Примеры предложений

- My **pen friend** lives in another **country**. (Мой друг по переписке живёт в другой стране.)
- **I'm writing to tell you** about my **hobby**. (Я пишу, чтобы рассказать тебе о своём хобби.)
- Please **write back soon**! (Пожалуйста, напиши в ответ скорее!)
- I got a **letter** and I will **reply** tomorrow. (Я получил письмо и отвечу завтра.)

## Мини-практика

1. Переведи фразу Write back soon — **Напиши в ответ скорее**.
2. Составь начало письма: Дорогой Том, — **Dear Tom,**.
3. Переведи слово favourite — **любимый**.
4. Как будет «отвечать (на письмо)» на английском? — **reply**.
5. Переведи предложение: My hobby is reading. — **Моё хобби — чтение.**
