# Каникулы и путешествия: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| holidays | каникулы |
| travel | путешествовать |
| trip | поездка |
| sea | море |
| mountains | горы |
| beach | пляж |
| suitcase | чемодан |
| ticket | билет |
| hotel | отель |
| abroad | за границей |
| arrive | прибывать |
| camera | фотоаппарат |
| souvenir | сувенир |
| plane | самолёт |
| train | поезд |

Примеры:
- I packed my **suitcase** for the **trip**. (Я собрал чемодан для поездки.)
- We stayed at a nice **hotel** near the **beach**. (Мы жили в хорошем отеле недалеко от пляжа.)
- Don't forget your **ticket** and **camera**. (Не забудь билет и фотоаппарат.)

## Мини-практика

1. Переведи слово suitcase — **чемодан**.
2. Как по-английски «за границей»? — **abroad**.
3. Переведи слово souvenir — **сувенир**.
4. Как по-английски «отель»? — **hotel**.
5. Переведи слово mountains — **горы**.
6. Переведи слово arrive — **прибывать**.
