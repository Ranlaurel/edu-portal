# Погода: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| weather | погода |
| sunny | солнечно |
| rainy | дождливо |
| windy | ветрено |
| snowy | снежно |
| cloudy | облачно |
| cold | холодно |
| hot | жарко |
| warm | тепло |
| It's raining | Идёт дождь |
| It's snowing | Идёт снег |
| umbrella | зонт |

Примеры:
- The **weather** is nice today. (Сегодня хорошая погода.)
- Take an **umbrella**, it's **rainy**. (Возьми зонт, дождливо.)
- It's **cloudy** and **windy**. (Облачно и ветрено.)

## Мини-практика

1. Переведи слово windy — **ветрено**.
2. Как по-английски «зонт»? — **umbrella**.
3. Переведи слово cloudy — **облачно**.
4. Как по-английски «тепло»? — **warm**.
5. Переведи слово snowy — **снежно**.
6. Переведи слово weather — **погода**.
