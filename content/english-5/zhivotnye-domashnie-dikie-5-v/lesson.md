# Животные: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| animal | животное |
| pet | домашнее животное (питомец) |
| wild animal | дикое животное |
| dog | собака |
| cat | кошка |
| rabbit | кролик |
| lion | лев |
| elephant | слон |
| tiger | тигр |
| bear | медведь |
| monkey | обезьяна |
| zoo | зоопарк |

Примеры:
- My **pet** is a **rabbit**. (Мой питомец — кролик.)
- A **lion** is a wild animal. (Лев — дикое животное.)
- We saw a **tiger** and a **bear** at the **zoo**. (Мы видели тигра и медведя в зоопарке.)

## Мини-практика

1. Переведи слово wild animal — **дикое животное**.
2. Как по-английски «зоопарк»? — **zoo**.
3. Переведи слово pet — **питомец**.
4. Как по-английски «обезьяна»? — **monkey**.
5. Переведи слово elephant — **слон**.
6. Переведи слово rabbit — **кролик**.
