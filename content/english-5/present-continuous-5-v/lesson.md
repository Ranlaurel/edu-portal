# Что происходит сейчас: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| now | сейчас |
| at the moment | в данный момент |
| play | играть |
| watch TV | смотреть телевизор |
| read | читать |
| write | писать |
| listen to music | слушать музыку |
| swim | плавать |
| run | бегать |
| cook | готовить (еду) |
| sleep | спать |
| look | смотреть, выглядеть |

## Мини-практика

1. Переведи слово swim — **плавать**.
2. Переведи слово sleep — **спать**.
3. Как по-английски «смотреть телевизор»? — **watch TV**.
4. Переведи слово run — **бегать**.
5. Как по-английски «слушать музыку»? — **listen to music**.
6. Переведи слово cook — **готовить (еду)**.
