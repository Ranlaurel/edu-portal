# Дни недели, месяцы, времена года: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| Monday | понедельник |
| Friday | пятница |
| Sunday | воскресенье |
| January | январь |
| May | май |
| September | сентябрь |
| December | декабрь |
| spring | весна |
| summer | лето |
| autumn | осень |
| winter | зима |
| month | месяц |

Дни недели, месяцы и времена года пишутся с **большой буквы** (кроме времён года — они пишутся с маленькой).

- **Monday** is the first school day. (Понедельник — первый учебный день.)
- **December** is a winter month. (Декабрь — зимний месяц.)

## Мини-практика

1. Напиши по-английски «пятница» с большой буквы — **Friday**.
2. Переведи слово autumn — **осень**.
3. Назови все четыре времени года по-английски — **spring, summer, autumn, winter**.
4. Переведи слово month — **месяц**.
5. Как по-английски «воскресенье»? — **Sunday**.
6. Переведи слово January — **январь**.
