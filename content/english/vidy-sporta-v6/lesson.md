# Виды спорта — слова

## Слова по теме

| Английский | Перевод |
|---|---|
| sport | спорт |
| football | футбол |
| basketball | баскетбол |
| volleyball | волейбол |
| tennis | теннис |
| swimming | плавание |
| running | бег |
| skiing | лыжи |
| chess | шахматы |
| gymnastics | гимнастика |
| athlete | спортсмен |
| team | команда |
| ball | мяч |
| training | тренировка |
| exercise | упражнение |

## Примеры предложений

- My favourite **sport** is **basketball**. (Мой любимый спорт — баскетбол.)
- Our **team** trains every week. (Наша команда тренируется каждую неделю.)
- She is a professional **athlete**. (Она профессиональная спортсменка.)
- I like **swimming** and **chess**. (Мне нравятся плавание и шахматы.)

## Мини-практика

1. Переведи слово athlete — **спортсмен**.
2. Как будет «тренировка» на английском? — **training**.
3. Переведи слово exercise — **упражнение**.
4. Как по-английски «команда»? — **team**.
5. Переведи предложение: I play volleyball and tennis. — **Я играю в волейбол и теннис.**
