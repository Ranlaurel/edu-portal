# Погода и климат (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| weather | погода |
| climate | климат |
| sunny | солнечный |
| rainy | дождливый |
| windy | ветреный |
| cloudy | облачный |
| snowy | снежный |
| foggy | туманный |
| temperature | температура |
| degree | градус |
| season | время года |
| forecast | прогноз |
| cold | холодный |
| hot | жаркий |
| wet | влажный, мокрый |

## Мини-практика

1. Переведи слово temperature — **температура**.
2. Переведи foggy — **туманный**.
3. Как будет «прогноз» на английском? — **forecast**.
4. Переведи слово degree — **градус**.
5. Чем weather отличается от climate? — **weather — погода сейчас/сегодня, climate — климат, обычная погода в местности за долгое время**.
6. Переведи слово season — **время года**.
