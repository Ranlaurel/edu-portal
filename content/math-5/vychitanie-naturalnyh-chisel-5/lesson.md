# Вычитание натуральных чисел

## Вычитание и его компоненты
Вычитание — действие, обратное сложению. Число, из которого вычитают, называется **уменьшаемым**, число, которое вычитают, — **вычитаемым**, а результат — **разностью**.
Пример: 50 − 18 = 32. Здесь 50 — уменьшаемое, 18 — вычитаемое, 32 — разность.
Вычитать можно только из большего числа меньшее (или равное число, тогда разность будет 0): натуральных чисел меньше нуля не бывает.
Связь сложения и вычитания: если a − b = c, то c + b = a. Это позволяет проверять вычитание сложением: 32 + 18 = 50 — верно.

## Вычитание столбиком
Многозначные числа вычитают столбиком, поразрядно справа налево, начиная с единиц. Если цифра уменьшаемого меньше цифры вычитаемого в этом разряде, «занимают» десяток из следующего разряда.
Пример: 542 − 268. Единицы: 2 − 8 нельзя, занимаем десяток: 12 − 8 = 4, из десятков уменьшаемого забрали 1. Десятки: было 4, стало 3, 3 − 6 нельзя, занимаем сотню: 13 − 6 = 7, из сотен забрали 1. Сотни: было 5, стало 4, 4 − 2 = 2. Получаем **542 − 268 = 274**.

## Свойства вычитания
Если из числа вычесть 0, число не изменится: **a − 0 = a**. Например, 25 − 0 = 25.
Если из числа вычесть само это число, получится 0: **a − a = 0**. Например, 25 − 25 = 0.
Чтобы вычесть из числа сумму, можно вычитать слагаемые по очереди: **a − (b + c) = a − b − c**.
Пример: 100 − (30 + 20) = 100 − 30 − 20 = 70 − 20 = **50**.

## Мини-практика
1. Найди разность: 542 − 268 — **274** (вычитание столбиком с занятием десятков и сотен).
2. Проверь сложением равенство 32 + 18 = 50 — **верно** (значит 50 − 18 = 32 тоже верно).
3. Найди значение: 25 − 0 — **25** (вычитание нуля не меняет число).
4. Найди значение: 40 − 40 — **0** (число минус само себя равно 0).
5. Вычисли удобным способом: 100 − 30 − 20 — **50** (сначала 100 − 30 = 70, потом 70 − 20 = 50).
6. Уменьшаемое 90, вычитаемое 37. Найди разность — **53** (90 − 37 = 53).
