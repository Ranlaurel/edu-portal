# Школьная жизнь и предметы — слова

## Слова по теме

| Английский | Перевод |
|---|---|
| subject | предмет (школьный) |
| maths | математика |
| science | естествознание |
| history | история |
| geography | география |
| art | рисование |
| PE (physical education) | физкультура |
| timetable | расписание |
| lesson | урок |
| break | перемена |
| classroom | класс (кабинет) |
| homework | домашнее задание |
| exam | экзамен |
| mark | оценка |
| schoolbag | школьный рюкзак |

## Примеры предложений

- My favourite **subject** is **history**. (Мой любимый предмет — история.)
- We have five **lessons** and two **breaks** today. (У нас пять уроков и две перемены сегодня.)
- I got a good **mark** for my **homework**. (Я получил хорошую оценку за домашнее задание.)
- Check the **timetable** for the next **exam**. (Посмотри расписание на следующий экзамен.)

## Мини-практика

1. Переведи слово timetable — **расписание**.
2. Переведи слово break — **перемена**.
3. Как будет «оценка» на английском? — **mark**.
4. Как по-английски «домашнее задание»? — **homework**.
5. Переведи предложение: My favourite subject is geography. — **Мой любимый предмет — география.**
