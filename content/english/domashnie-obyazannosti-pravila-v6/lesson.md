# Домашние обязанности: слова по теме

## Слова по теме

| Английский | Перевод |
|---|---|
| clean the room | убирать комнату |
| wash up | мыть посуду |
| tidy up | наводить порядок |
| water the plants | поливать растения |
| lay the table | накрывать на стол |
| take out the rubbish | выносить мусор |
| walk the dog | выгуливать собаку |
| make the bed | заправлять кровать |
| do the shopping | ходить за покупками |
| vacuum | пылесосить |
| rule | правило |
| chore | домашняя обязанность |
| allowed | разрешено |
| forbidden | запрещено |
| duty | обязанность |

## Примеры предложений

- My **chore** is to **wash up** after dinner. (Моя обязанность — мыть посуду после ужина.)
- It is **forbidden** to eat in the bedroom. (Есть в спальне запрещено.)
- I **vacuum** the living room every Saturday. (Я пылесошу гостиную каждую субботу.)

## Мини-практика

1. Переведи слово chore — **домашняя обязанность**.
2. Как будет «выносить мусор» на английском? — **take out the rubbish**.
3. Переведи слово forbidden — **запрещено**.
4. Как по-английски «поливать растения»? — **water the plants**.
5. Переведи фразу «наводить порядок» — **tidy up**.
