## Грамматика: some / any

**Some** используем в утвердительных предложениях, **any** — в вопросах и отрицаниях.

- There **is some** milk in the fridge. (В холодильнике есть немного молока.)
- I've got **some** apples. (У меня есть яблоки.)
- **Is there any** juice? (Есть сок?)
- There **isn't any** bread. (Хлеба нет.)

С исчисляемыми существительными во множественном числе (apples, eggs) и с неисчисляемыми (milk, bread, sugar) правило одинаковое.

## Мини-практика

1. Вставь: There is ___ milk in the fridge. — **some**.
2. Вставь: Is there ___ juice? — **any**.
3. Переведи слово sugar — **сахар**.
4. Составь отрицание: There is some bread. → **There isn't any bread.**
5. Переведи: У меня есть немного яблок. — **I've got some apples.**
6. Как по-английски «сладости»? — **sweets**.
