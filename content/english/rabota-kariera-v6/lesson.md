# Работа и карьера (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| work | работать; работа |
| earn | зарабатывать |
| salary | зарплата |
| workplace | место работы |
| career | карьера |
| apply for a job | подавать заявку на работу |
| employee | сотрудник |
| employer | работодатель |
| interview | собеседование |
| experience | опыт |
| skill | навык |
| colleague | коллега |
| promotion | повышение (по должности) |
| full-time | полная занятость |
| part-time | частичная занятость |

## Примеры предложений

- She got a **promotion** after two years of hard **work**. (Она получила повышение
после двух лет упорной работы.)
- My **colleague** has a lot of **experience** in this **career**. (У моего коллеги
большой опыт в этой карьере.)
- He wants a **part-time** job to **earn** some money. (Он хочет частичную занятость,
чтобы немного заработать.)

## Мини-практика

1. Переведи слово salary — **зарплата**.
2. Переведи career — **карьера**.
3. Как будет «собеседование» на английском? — **interview**.
4. Переведи фразу apply for a job — **подавать заявку на работу**.
5. Как по-английски «работодатель»? — **employer**.
