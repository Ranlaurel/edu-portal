## 📋 Выполненные задачи

### 1. ✅ Многопользовательская авторизация

**Реализовано:**
- Таблица `users` с полями: `id`, `username`, `password_hash`, `display_name`, `is_active`
- Безопасное хеширование паролей: PBKDF2-SHA256, 240,000 итераций + случайная соль
- Middleware для проверки аутентификации
- Защита от timing attacks через `hmac.compare_digest()`
- Bootstrap-пользователь создаётся автоматически из переменных окружения

**Безопасность:**
- HttpOnly session cookies
- Подписанные сессии через `SECRET_KEY`
- SQL-инъекции защищены через SQLAlchemy ORM
- Внешние ключи для целостности данных

**Файлы:**
- `app/models.py` — User model + foreign keys
- `app/auth.py` — authentication logic
- `app/routers/auth.py` — login/logout endpoints
- `app/main.py` — middleware integration
