# Сложение градусных мер углов

## Луч делит угол на два угла
Если внутри угла провести луч из его вершины, он разделит угол на два меньших угла. Тогда сумма градусных мер этих двух углов равна градусной мере всего угла.
Например, луч OB проходит внутри угла AOC. Тогда: **∠AOB + ∠BOC = ∠AOC**.
Если ∠AOB = 35° и ∠BOC = 45°, то весь угол ∠AOC = 35° + 45° = **80°**.

## Нахождение неизвестной части угла
Зная весь угол и одну из его частей, можно найти вторую часть — вычитанием.
Пусть ∠AOC = 90°, а луч OB делит его так, что ∠AOB = 35°. Тогда ∠BOC = ∠AOC − ∠AOB = 90° − 35° = **55°**.
Проверка: 35° + 55° = 90° — верно, части в сумме дают весь угол.
Ещё пример: ∠MON = 140°, ∠MOK = 60°. Тогда ∠KON = 140° − 60° = **80°**.

## Мини-практика
1. Луч OB делит угол AOC на части 20° и 30°. Чему равен угол AOC? — **50°** (20° + 30° = 50°).
2. Угол AOC = 100°, часть ∠AOB = 40°. Найди ∠BOC — **60°** (100° − 40° = 60°).
3. Угол разделён на две части по 45° каждая. Чему равен весь угол? — **90°** (45° + 45° = 90°).
4. Весь угол 120°, одна часть 75°. Найди вторую часть — **45°** (120° − 75° = 45°).
5. Части угла равны 55° и 65°. Чему равен весь угол? — **120°** (55° + 65° = 120°).
