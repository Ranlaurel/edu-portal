# Еда и напитки: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| food | еда |
| drink | напиток |
| bread | хлеб |
| cheese | сыр |
| milk | молоко |
| juice | сок |
| apple | яблоко |
| egg | яйцо |
| sugar | сахар |
| water | вода |
| rice | рис |
| sweets | сладости |

Примеры:
- I like **cheese** and **bread**. (Мне нравятся сыр и хлеб.)
- Can I have some **juice**, please? (Можно мне сок?)
- We need **rice** and **eggs** for dinner. (Нам нужны рис и яйца на ужин.)

## Мини-практика

1. Переведи слово sugar — **сахар**.
2. Как по-английски «сладости»? — **sweets**.
3. Переведи слово juice — **сок**.
4. Как по-английски «рис»? — **rice**.
5. Переведи слово egg — **яйцо**.
6. Переведи слово drink — **напиток**.
