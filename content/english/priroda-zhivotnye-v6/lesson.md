# Природа: животные (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| wild animal | дикое животное |
| pet | домашнее животное |
| lion | лев |
| elephant | слон |
| tiger | тигр |
| bear | медведь |
| wolf | волк |
| fox | лиса |
| rabbit | кролик |
| hamster | хомяк |
| forest | лес |
| jungle | джунгли |
| tail | хвост |
| fur | шерсть |
| dangerous | опасный |

## Мини-практика

1. Переведи слово fur — **шерсть**.
2. Переведи dangerous — **опасный**.
3. Как будет «хомяк» на английском? — **hamster**.
4. Переведи слово jungle — **джунгли**.
5. Чем отличаются wild animal и pet? — **wild animal — дикое, живёт в природе; pet — домашнее, живёт с человеком**.
6. Переведи слово tail — **хвост**.
