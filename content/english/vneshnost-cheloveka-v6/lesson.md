# Внешность: слова по теме

## Слова по теме

| Английский | Перевод |
|---|---|
| tall | высокий |
| short | невысокий |
| slim | стройный |
| well-built | крепкого телосложения |
| hair | волосы |
| curly | кудрявые |
| straight | прямые |
| fair hair | светлые волосы |
| dark hair | тёмные волосы |
| eyes | глаза |
| blue-eyed | голубоглазый |
| beard | борода |
| moustache | усы |
| freckles | веснушки |
| appearance | внешность |

## Примеры предложений

- Her **appearance** is very nice. (Её внешность очень приятная.)
- He has got **dark hair** and **freckles**. (У него тёмные волосы и веснушки.)
- My dad has got a **beard** and a **moustache**. (У моего папы борода и усы.)

## Мини-практика

1. Переведи слово freckles — **веснушки**.
2. Как будет «кудрявые» на английском? — **curly**.
3. Переведи слово appearance — **внешность**.
4. Как по-английски «крепкого телосложения»? — **well-built**.
5. Переведи слово moustache — **усы**.
