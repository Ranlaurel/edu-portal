# Что происходит сейчас

## Слова по теме

| Английский | Перевод |
|---|---|
| now | сейчас |
| at the moment | в данный момент |
| play | играть |
| watch TV | смотреть телевизор |
| read | читать |
| write | писать |
| listen to music | слушать музыку |
| swim | плавать |
| run | бегать |
| cook | готовить (еду) |
| sleep | спать |
| look | смотреть, выглядеть |

## Грамматика: Present Continuous

Используем, чтобы говорить о действии, которое происходит **прямо сейчас**. Формула: **am/is/are + глагол-ing**.

- I **am reading** a book now. (Я сейчас читаю книгу.)
- He **is playing** football at the moment. (Он сейчас играет в футбол.)
- They **are watching** TV. (Они смотрят телевизор.)

Правила добавления -ing: обычно просто добавляем -ing (**play → playing**), если слово оканчивается на -e, убираем её (**write → writing**), если на согласную+гласную+согласную — удваиваем последнюю (**swim → swimming**).

Отрицание: **am not / isn't / aren't + глагол-ing**.
- She **isn't sleeping** now. (Она сейчас не спит.)

Вопрос: **Am/Is/Are + подлежащее + глагол-ing?**
- **Is** he **cooking** dinner? — Yes, he **is**. (Он готовит ужин?)

## Мини-практика

1. Вставь: I ___ (read) a book now. — **am reading**.
2. Образуй -ing форму от swim — **swimming** (удвоение согласной).
3. Составь отрицание: She is sleeping. → **She isn't sleeping.**
4. Задай вопрос: They are watching TV. → **Are they watching TV?**
5. Образуй -ing форму от write — **writing**.
6. Переведи: Он сейчас слушает музыку. — **He is listening to music now.**
