# Город: места и направления

## Слова по теме

| Английский | Перевод |
|---|---|
| street | улица |
| park | парк |
| hospital | больница |
| library | библиотека |
| museum | музей |
| bridge | мост |
| square | площадь |
| bank | банк |
| station | вокзал, станция |
| turn left | повернуть налево |
| turn right | повернуть направо |
| go straight | идти прямо |

## Грамматика: предлоги места

Предлоги места показывают, где находится объект.

- **in** — внутри: The library is **in** the park. (Библиотека **в** парке.)
- **on** — на поверхности: The bank is **on** Green Street. (Банк **на** улице Грин.)
- **near** — рядом: The station is **near** the museum. (Вокзал **рядом с** музеем.)
- **next to** — прямо рядом, около: The hospital is **next to** the school. (Больница **около** школы.)
- **opposite** — напротив: The park is **opposite** the bank. (Парк **напротив** банка.)
- **between** — между: The bridge is **between** the park and the square. (Мост **между** парком и площадью.)

## Мини-практика

1. Как сказать «библиотека рядом с музеем»? — **The library is near the museum**.
2. Переведи слово square — **площадь**.
3. Впиши предлог: The bank is ___ the hospital and the park (между). — **between**.
4. Как будет «повернуть налево» на английском? — **turn left**.
5. Составь предложение: банк напротив вокзала. — **The bank is opposite the station**.
6. Переведи слово bridge — **мост**.
