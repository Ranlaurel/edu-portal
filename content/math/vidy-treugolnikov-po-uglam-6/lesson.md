# Виды треугольников по углам

## Остроугольный, прямоугольный и тупоугольный треугольники
По величине углов треугольники делятся на три вида. Сумма всех углов любого треугольника всегда равна **180°**.
**Остроугольный треугольник** — все три угла острые (меньше 90°).
Пример: углы 60°, 70°, 50° — все меньше 90°, треугольник **остроугольный** (60+70+50=180).
**Прямоугольный треугольник** — один из углов прямой (ровно 90°); стороны, образующие прямой угол, называются катетами, а сторона напротив прямого угла — гипотенузой.
Пример: углы 90°, 40°, 50° — один угол прямой, треугольник **прямоугольный** (90+40+50=180).
**Тупоугольный треугольник** — один из углов тупой (больше 90°).
Пример: углы 120°, 30°, 30° — один угол тупой, треугольник **тупоугольный** (120+30+30=180).

## Нахождение неизвестного угла треугольника
Если известны два угла треугольника, третий находят вычитанием их суммы из 180°: **третий угол = 180° − (первый + второй)**.
Пример: два угла треугольника равны 55° и 65°. Третий угол: 180° − (55° + 65°) = 180° − 120° = **60°** — треугольник остроугольный.
Пример: два угла треугольника равны 90° и 35°. Третий угол: 180° − (90° + 35°) = 180° − 125° = **55°** — треугольник прямоугольный (есть угол 90°).
В любом треугольнике не может быть двух прямых или двух тупых углов одновременно, иначе сумма углов превысила бы 180°.

## Мини-практика
1. Углы треугольника 45°, 45°, 90°. Определи вид — **прямоугольный** (есть угол 90°).
2. Углы треугольника 100°, 40°, 40°. Определи вид — **тупоугольный** (есть угол больше 90°).
3. Два угла треугольника 50° и 60°. Найди третий угол — **70°** (180 − (50+60) = 70).
4. Углы треугольника 60°, 60°, 60°. Определи вид — **остроугольный** (все углы меньше 90°).
5. Два угла треугольника 90° и 45°. Найди третий угол — **45°** (180 − (90+45) = 45).
6. Может ли в треугольнике быть два тупых угла — **нет**, сумма всех углов была бы больше 180°.
