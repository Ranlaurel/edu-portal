# Сложение дробей с разными знаменателями

## Правило сложения
Чтобы сложить дроби с разными знаменателями, их сначала приводят к общему знаменателю (обычно к НОК знаменателей), затем складывают числители, а знаменатель оставляют без изменений. Если результат сокращается — его сокращают, если числитель больше знаменателя — выделяют целую часть.

Пример: 1/4 + 1/6. НОК(4, 6) = 12. Приводим: 1/4 = 3/12, 1/6 = 2/12. Складываем: 3/12 + 2/12 = **5/12**.

Пример: 2/3 + 1/6. НОК(3, 6) = 6. Приводим: 2/3 = 4/6. Складываем: 4/6 + 1/6 = **5/6**.

Пример: 5/6 + 1/3. НОК(6, 3) = 6. Приводим: 1/3 = 2/6. Складываем: 5/6 + 2/6 = 7/6 = **1 1/6** (числитель больше знаменателя — выделили целую часть).

## Сложение смешанных чисел
У смешанных чисел отдельно складывают целые части и отдельно — дробные, затем при необходимости объединяют результат.

Пример: 1 1/2 + 2 1/3. Целые части: 1 + 2 = 3. Дробные части: 1/2 + 1/3, НОК(2, 3) = 6, получаем 3/6 + 2/6 = 5/6. Итог: 3 + 5/6 = **3 5/6**.

## Мини-практика
1. Сложи 1/3 + 1/4 — **7/12** (НОК=12: 4/12+3/12=7/12).
2. Сложи 1/2 + 1/6 — **2/3** (НОК=6: 3/6+1/6=4/6=2/3 после сокращения).
3. Сложи 3/4 + 1/2 — **1 1/4** (НОК=4: 3/4+2/4=5/4=1 1/4).
4. Сложи 2 1/4 + 1 1/2 — **3 3/4** (целые: 2+1=3; дробные: 1/4+2/4=3/4).
5. Сложи 5/8 + 1/4 — **7/8** (НОК=8: 5/8+2/8=7/8).
6. Сложи 1/5 + 2/3 — **13/15** (НОК=15: 3/15+10/15=13/15).
