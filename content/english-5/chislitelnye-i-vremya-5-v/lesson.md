# Числительные и время: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| twenty | двадцать |
| thirty | тридцать |
| forty | сорок |
| fifty | пятьдесят |
| hundred | сто |
| o'clock | час (ровно) |
| half past | половина |
| quarter | четверть |
| minute | минута |
| hour | час (промежуток) |
| What time is it? | Который час? |
| It's... | Сейчас... |

Числа от 20 до 90 образуются с окончанием **-ty**: twenty (20), thirty (30), forty (40), fifty (50). Между десятками и единицами пишем дефис: **twenty-one** (21), **fifty-six** (56).

- There are **thirty** pupils in our class. (В нашем классе тридцать учеников.)
- My grandmother is **fifty-two**. (Моей бабушке пятьдесят два года.)

## Мини-практика

1. Напиши число 40 словом — **forty**.
2. Напиши число 25 словом — **twenty-five**.
3. Переведи слово minute — **минута**.
4. Переведи слово hour — **час (промежуток)**.
5. Как по-английски «сто»? — **hundred**.
6. Переведи слово quarter — **четверть**.
