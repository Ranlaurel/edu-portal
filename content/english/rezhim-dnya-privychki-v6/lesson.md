# Режим дня и полезные привычки (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| get up | вставать |
| wake up | просыпаться |
| have breakfast | завтракать |
| have lunch | обедать |
| have dinner | ужинать |
| go to school | идти в школу |
| do homework | делать домашнее задание |
| go to bed | ложиться спать |
| brush teeth | чистить зубы |
| take a shower | принимать душ |
| get dressed | одеваться |
| habit | привычка |
| routine | распорядок дня |
| early | рано |
| late | поздно |

## Примеры предложений

- I **wake up** at seven, then **get up** and **get dressed**. (Я просыпаюсь в семь,
потом встаю и одеваюсь.)
- We **have dinner** together and then **do homework**. (Мы вместе ужинаем, а потом
делаем домашнее задание.)
- It's a bad **habit** to **go to bed** too **late**. (Это плохая привычка —
ложиться спать слишком поздно.)

## Мини-практика

1. Переведи слово routine — **распорядок дня**.
2. Переведи фразу «делать домашнее задание» — **do homework**.
3. Как будет «принимать душ» на английском? — **take a shower**.
4. Переведи слово habit — **привычка**.
5. Как по-английски «чистить зубы»? — **brush teeth**.
