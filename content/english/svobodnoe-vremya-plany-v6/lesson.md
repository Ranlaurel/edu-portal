# Свободное время: слова по теме

## Слова по теме

| Английский | Перевод |
|---|---|
| free time | свободное время |
| weekend | выходные |
| plan | план |
| meet friends | встречаться с друзьями |
| go shopping | ходить по магазинам |
| visit | навещать |
| relax | отдыхать, расслабляться |
| go for a walk | гулять |
| watch a film | смотреть фильм |
| have a party | устраивать вечеринку |
| stay at home | оставаться дома |
| arrangement | договорённость |
| tomorrow | завтра |
| on Saturday | в субботу |
| next week | на следующей неделе |

## Примеры предложений

- I like to **relax** at **weekend**. (Мне нравится отдыхать на выходных.)
- We have an **arrangement** to **watch a film**. (У нас есть договорённость посмотреть фильм.)
- My **plan** is to **stay at home** tomorrow. (Мой план — остаться дома завтра.)

## Мини-практика

1. Переведи слово arrangement — **договорённость**.
2. Как будет «отдыхать» на английском? — **relax**.
3. Переведи фразу «go for a walk» — **гулять**.
4. Как по-английски «устраивать вечеринку»? — **have a party**.
5. Переведи слово weekend — **выходные**.
