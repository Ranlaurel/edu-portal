# Правила поведения в школе — слова

## Слова по теме

| Английский | Перевод |
|---|---|
| rule | правило |
| behave | вести себя |
| uniform | школьная форма |
| corridor | коридор |
| be quiet | вести себя тихо |
| be late | опаздывать |
| shout | кричать |
| run | бегать |
| listen to | слушать |
| put up your hand | поднимать руку |
| mobile phone | мобильный телефон |
| respect | уважать |
| tidy | аккуратный |
| permission | разрешение |
| headteacher | директор школы |

## Примеры предложений

- Every school has its own **rules**. (В каждой школе есть свои правила.)
- Students must **behave** well in the **corridor**. (Ученики должны хорошо себя вести в коридоре.)
- Ask for **permission** before you leave the classroom. (Спроси разрешение, прежде чем выйти из класса.)
- We must **respect** the **headteacher**. (Мы должны уважать директора школы.)

## Мини-практика

1. Переведи слово permission — **разрешение**.
2. Переведи слово headteacher — **директор школы**.
3. Как будет «опаздывать» на английском? — **be late**.
4. Как по-английски «поднимать руку»? — **put up your hand**.
5. Переведи предложение: Students must be quiet in the corridor. — **Ученики должны вести себя тихо в коридоре.**
