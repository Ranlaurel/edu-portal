# Знаменитые путешественники и открытия — слова

## Слова по теме

| Английский | Перевод |
|---|---|
| explorer | путешественник, исследователь |
| explore | исследовать |
| discover | открывать (что-то новое) |
| discovery | открытие |
| voyage | морское путешествие |
| expedition | экспедиция |
| sail | плыть (на корабле) |
| land | суша, земля; высаживаться |
| continent | континент |
| island | остров |
| brave | смелый |
| famous | знаменитый |
| route | маршрут |
| ship | корабль |
| adventure | приключение |

## Примеры предложений

- The **explorer** started a long **voyage** across the ocean. (Путешественник начал долгое морское путешествие через океан.)
- They found a new **island** during the **expedition**. (Они нашли новый остров во время экспедиции.)
- Every great **discovery** needs a **brave** person. (Каждое великое открытие требует смелого человека.)
- Their **ship** followed a dangerous **route**. (Их корабль следовал опасным маршрутом.)

## Мини-практика

1. Переведи слово discovery — **открытие**.
2. Переведи expedition — **экспедиция**.
3. Как будет «смелый» на английском? — **brave**.
4. Как по-английски «континент»? — **continent**.
5. Переведи предложение: The ship sailed to a new continent. — **Корабль приплыл к новому континенту.**
