# Построение точек и фигур по координатам

## Построение точки по координатам

Чтобы построить точку A(3; 5): от начала координат сдвигаемся на **3 единицы вправо** по оси Ox, затем на **5 единиц вверх** по оси Oy — здесь и будет точка A.

Точка B(−4; 2): 4 единицы **влево** по оси Ox (минус — значит влево), 2 единицы вверх по оси Oy.

Точка C(2; −3): 2 единицы вправо, 3 единицы **вниз** по оси Oy (минус — значит вниз).

Точка D(−5; −1): 5 единиц влево и 1 единица вниз — обе координаты отрицательны.

## Точки на осях

Точка D(0; 4) лежит прямо на оси Oy, потому что её абсцисса равна нулю — сдвига по Ox нет, только на 4 вверх. Точка E(−5; 0) лежит на оси Ox, потому что её ордината равна нулю — сдвига по Oy нет, только на 5 влево.

## Четверти координатной плоскости

Оси делят плоскость на 4 части — **четверти**, пронумерованные против часовой стрелки начиная с правой верхней:
- **I четверть**: x > 0, y > 0 (обе положительные) — точка (2; 3).
- **II четверть**: x < 0, y > 0 — точка (−2; 3).
- **III четверть**: x < 0, y < 0 (обе отрицательные) — точка (−2; −3).
- **IV четверть**: x > 0, y < 0 — точка (2; −3).

Зная знаки координат, легко сказать, в какой четверти лежит точка, не строя чертёж: например, у точки (−6; 4) x < 0 и y > 0 — значит, она во **II четверти**.

## Мини-практика

1. В какую сторону сдвигаемся по Ox для точки с абсциссой −7? — **влево** (отрицательная абсцисса — сдвиг влево)
2. В какой четверти лежит точка (−3; −8)? — **III четверть** (обе координаты отрицательны)
3. На какой оси лежит точка (0; −6)? — **на оси Oy** (абсцисса равна нулю)
4. В какой четверти лежит точка (5; −2)? — **IV четверть** (x > 0, y < 0)
5. На какой оси лежит точка (9; 0)? — **на оси Ox** (ордината равна нулю)
6. В какой четверти лежит точка (1; 1)? — **I четверть** (обе координаты положительны)
