# Хобби: слова по теме

## Слова по теме

| Английский | Перевод |
|---|---|
| hobby | хобби |
| collect | коллекционировать |
| paint | рисовать красками |
| draw | рисовать (карандашом) |
| play an instrument | играть на инструменте |
| play chess | играть в шахматы |
| dance | танцевать |
| sing | петь |
| knit | вязать |
| take photos | фотографировать |
| ride a bike | кататься на велосипеде |
| collection | коллекция |
| stamp | марка |
| skill | навык |
| interesting | интересный |

## Примеры предложений

- My **hobby** is an **interesting** **skill**. (Моё хобби — интересный навык.)
- She has a big **collection** of **stamps**. (У неё большая коллекция марок.)
- He can **play an instrument** and **sing**. (Он умеет играть на инструменте и петь.)

## Мини-практика

1. Переведи слово collection — **коллекция**.
2. Как будет «вязать» на английском? — **knit**.
3. Переведи слово skill — **навык**.
4. Как по-английски «фотографировать»? — **take photos**.
5. Переведи слово stamp — **марка**.
