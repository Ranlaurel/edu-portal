# Мебель и предметы в доме: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| furniture | мебель |
| table | стол |
| chair | стул |
| bed | кровать |
| sofa | диван |
| wardrobe | шкаф |
| shelf | полка |
| lamp | лампа |
| mirror | зеркало |
| carpet | ковёр |
| clock | часы |
| fridge | холодильник |

Примеры:
- We have got new **furniture**. (У нас новая мебель.)
- There is a **mirror** and a **lamp** in my room. (В моей комнате есть зеркало и лампа.)
- The **fridge** is in the kitchen. (Холодильник на кухне.)

## Мини-практика

1. Переведи слово wardrobe — **шкаф**.
2. Как по-английски «диван»? — **sofa**.
3. Переведи слово shelf — **полка**.
4. Как по-английски «ковёр»? — **carpet**.
5. Переведи слово fridge — **холодильник**.
6. Переведи слово mirror — **зеркало**.
