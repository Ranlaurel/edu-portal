# Указательные местоимения (this/that/these/those)

## Слова по теме

| Английский | Перевод |
|---|---|
| pencil | карандаш |
| chair | стул |
| window | окно |
| picture | картинка |
| shoes | туфли |
| flowers | цветы |
| near | близко |
| far | далеко |
| here | здесь |
| there | там |

## Грамматика: this/that/these/those

Указательные местоимения показывают, близко или далеко находится предмет, и в каком он числе.

|  | близко (здесь) | далеко (там) |
|---|---|---|
| единственное число | **this** (этот, эта, это) | **that** (тот, та, то) |
| множественное число | **these** (эти) | **those** (те) |

- **This** pencil is mine. (**Этот** карандаш мой — карандаш рядом.)
- **That** chair is broken. (**Тот** стул сломан — стул далеко.)
- **These** shoes are new. (**Эти** туфли новые — рядом.)
- **Those** flowers are beautiful. (**Те** цветы красивые — далеко.)

## Мини-практика

1. Как сказать «этот карандаш» (рядом)? — **this pencil**.
2. Как сказать «те цветы» (далеко, мн. число)? — **those flowers**.
3. Переведи слово window — **окно**.
4. Впиши местоимение: ___ shoes are new (туфли рядом, мн. число). — **these**.
5. Впиши местоимение: ___ chair is broken (стул далеко, ед. число). — **that**.
6. Как будет «картинка» на английском? — **picture**.
