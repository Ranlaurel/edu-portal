# Родная страна: география и культура (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| territory | территория |
| population | население |
| nationality | национальность |
| famous for | знаменитый (чем-то) |
| country | страна |
| continent | континент |
| river | река |
| lake | озеро |
| mountain | гора |
| forest | лес |
| culture | культура |
| language | язык |
| large | большой |
| deep | глубокий |
| long | длинный |

## Мини-практика

1. Переведи слово territory — **территория**.
2. Переведи слово nationality — **национальность**.
3. Как будет «континент» на английском? — **continent**.
4. Переведи слово culture — **культура**.
5. Чем country отличается от continent? — **country — страна, continent — материк, часть света (в состав которого входит несколько стран)**.
6. Переведи слово mountain — **гора**.
