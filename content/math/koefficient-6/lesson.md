# Коэффициент буквенного выражения

## Что такое коэффициент
В произведении числа и буквенного множителя число называют **коэффициентом**. Например, в выражении −3x коэффициент равен **−3**. В выражении 5a коэффициент равен **5**. В выражении 2,5b коэффициент равен **2,5**.
Если перед буквой не написано число, коэффициент равен **1** (в выражении x коэффициент равен 1). Если стоит только знак минус, коэффициент равен **−1** (в выражении −y коэффициент равен −1).

## Приведение подобных слагаемых
**Подобные слагаемые** — слагаемые с одинаковой буквенной частью (или вовсе без букв). Чтобы привести подобные слагаемые, нужно **сложить их коэффициенты**, а буквенную часть оставить без изменений.
Пример: 4x + 7x = (4 + 7)x = **11x**.
Пример: 5a − 9a = (5 − 9)a = **−4a**.
Пример: −3y + 8y − 2y = (−3 + 8 − 2)y = **3y**.
Пример: 6x + 3 − 2x + 5 = (6 − 2)x + (3 + 5) = **4x + 8** (слагаемые с x складываем отдельно от чисел без буквы).

## Мини-практика
1. Найди коэффициент в выражении −8m — **−8** (число перед буквой).
2. Найди коэффициент в выражении x — **1** (число перед буквой не написано).
3. Найди коэффициент в выражении −y — **−1** (стоит только знак минус).
4. Приведи подобные слагаемые: 6x + 9x — **15x** ((6+9)x).
5. Приведи подобные слагаемые: 7a − 12a — **−5a** ((7−12)a).
6. Приведи подобные слагаемые: 3x + 4 − x + 6 — **2x + 10** ((3−1)x + (4+6)).
