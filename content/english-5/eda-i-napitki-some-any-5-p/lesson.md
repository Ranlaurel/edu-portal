# Еда и напитки: диалог в магазине

## Слова по теме

| Английский | Перевод |
|---|---|
| shopping list | список покупок |
| enough | достаточно |
| need | нуждаться (в чём-то) |
| buy | покупать |

## Грамматика: some / any в разговоре

В диалогах про еду **some** и **any** встречаются вместе с исчисляемыми и
неисчисляемыми словами из темы «Еда и напитки»: bread, cheese, milk, juice,
apples, eggs, sugar, water, rice, sweets.

- A: Is there **any** cheese at home? (Дома есть сыр?)
- B: No, there isn't. But there is **some** rice. (Нет. Но есть немного риса.)
- A: We need **some** eggs and **some** juice. (Нам нужны яйца и сок.)
- B: OK, is there **any** sugar left? (Хорошо, а сахар остался?)

## Мини-практика

1. Составь вопрос: есть ли дома молоко? — **Is there any milk at home?**
2. Ответь утвердительно: есть немного хлеба. — **There is some bread.**
3. Переведи: Нам нужны яблоки и сыр. — **We need some apples and cheese.**
4. Составь отрицание: сахара не осталось. — **There isn't any sugar left.**
5. Переведи слово enough — **достаточно**.
6. Составь диалог-ответ: Is there any water? — Yes, ___ (немного). — **Yes, there is some.**
