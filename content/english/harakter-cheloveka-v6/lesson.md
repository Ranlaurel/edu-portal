# Характер: слова по теме

## Слова по теме

| Английский | Перевод |
|---|---|
| kind | добрый |
| friendly | дружелюбный |
| shy | застенчивый |
| brave | смелый |
| honest | честный |
| clever / smart | умный |
| lazy | ленивый |
| polite | вежливый |
| rude | грубый |
| generous | щедрый |
| curious | любопытный |
| stubborn | упрямый |
| cheerful | весёлый, жизнерадостный |
| patient | терпеливый |
| character | характер |

## Примеры предложений

- My best friend has a great **character**. (У моего лучшего друга отличный характер.)
- She is always **cheerful** and **friendly**. (Она всегда весёлая и дружелюбная.)
- He can be **stubborn**, but he is also **honest**. (Он может быть упрямым, но он также честный.)

## Мини-практика

1. Переведи слово generous — **щедрый**.
2. Как будет «терпеливый» на английском? — **patient**.
3. Переведи слово rude — **грубый**.
4. Как по-английски «любопытный»? — **curious**.
5. Переведи слово lazy — **ленивый**.
