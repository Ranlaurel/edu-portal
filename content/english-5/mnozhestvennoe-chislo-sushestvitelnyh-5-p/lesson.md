# Множественное число: слова-исключения

## Слова по теме

| Английский | Перевод |
|---|---|
| child | ребёнок |
| man | мужчина |
| woman | женщина |
| foot | нога (ступня) |
| tooth | зуб |

## Грамматика: слова-исключения

Есть слова с особым множественным числом, не по правилу -s:

- child → **children** (дети)
- man → **men** (мужчины)
- woman → **women** (женщины)
- foot → **feet** (ноги)
- tooth → **teeth** (зубы)

- I have got two **children**. (У меня двое детей.)
- Her **feet** hurt. (У неё болят ноги.)

## Мини-практика

1. Переведи слово tooth — **зуб**.
2. Как будет «дети» во множественном числе? — **children** (исключение).
3. Как будет «мужчины» во множественном числе? — **men** (исключение).
4. Как будет «зубы» во множественном числе? — **teeth** (исключение).
