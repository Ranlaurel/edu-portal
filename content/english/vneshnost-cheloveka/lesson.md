# Внешность человека

## Слова по теме

| Английский | Перевод |
|---|---|
| tall | высокий |
| short | невысокий |
| slim | стройный |
| well-built | крепкого телосложения |
| hair | волосы |
| curly | кудрявые |
| straight | прямые |
| fair hair | светлые волосы |
| dark hair | тёмные волосы |
| eyes | глаза |
| blue-eyed | голубоглазый |
| beard | борода |
| moustache | усы |
| freckles | веснушки |
| appearance | внешность |

## Грамматика: to be + adjective и has got (описание внешности)

Для описания общих черт (рост, телосложение) используем **to be + прилагательное**. Для описания того, что у человека есть (волосы, глаза), используем **has got / have got**.

- She **is tall** and **slim**. (Она высокая и стройная.)
- He **is well-built**. (Он крепкого телосложения.)
- My friend **has got** curly dark hair. (У моего друга кудрявые тёмные волосы.)
- She **has got** blue eyes. (У неё голубые глаза.)
- He **hasn't got** a beard. (У него нет бороды.)

Вопрос: **Has** he **got** a moustache? (У него есть усы?)

## Мини-практика

1. Как сказать «она высокая»? — **She is tall** (to be + adjective).
2. Впиши: My brother ___ got short fair hair. — **has** (has got — есть).
3. Переведи слово freckles — **веснушки**.
4. Составь предложение: у него нет бороды — **He hasn't got a beard**.
5. Как будет «кудрявые» на английском? — **curly**.
6. Переведи: She has got blue eyes and straight dark hair. — **У неё голубые глаза и прямые тёмные волосы.**
