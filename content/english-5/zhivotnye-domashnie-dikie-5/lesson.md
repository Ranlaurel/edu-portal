## Грамматика: can для описания способностей животных

**Can** — модальный глагол, показывает, что животное умеет делать. Формула одинакова для всех: **can + глагол** (без -s, без to).

- A monkey **can** climb trees. (Обезьяна умеет лазить по деревьям.)
- A tiger **can** run fast. (Тигр умеет быстро бегать.)
- Fish **can't** live without water. (Рыбы не могут жить без воды.)

Вопрос: **Can** выходит на первое место.
- **Can** a bear swim? — Yes, it **can**. (Медведь умеет плавать?)

## Мини-практика

1. Переведи слово wild animal — **дикое животное**.
2. Вставь: A monkey ___ (climb) trees. — **can climb**.
3. Составь отрицание: A dog can fly. → **A dog can't fly.**
4. Задай вопрос: A tiger can run fast. → **Can a tiger run fast?**
5. Как по-английски «зоопарк»? — **zoo**.
6. Переведи: Слон большой и сильный. — **An elephant is big and strong.**
