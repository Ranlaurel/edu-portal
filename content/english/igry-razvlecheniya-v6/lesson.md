# Игры: слова по теме

## Слова по теме

| Английский | Перевод |
|---|---|
| game | игра |
| board game | настольная игра |
| video game | видеоигра |
| play | играть |
| win | выигрывать |
| lose | проигрывать |
| team | команда |
| player | игрок |
| rules | правила игры |
| score | счёт |
| turn | ход, очередь |
| puzzle | головоломка |
| card game | карточная игра |
| fun | веселье |
| outdoor game | игра на улице |

## Примеры предложений

- This **board game** has difficult **rules**. (У этой настольной игры сложные правила.)
- Our **team** needs one more **player**. (Нашей команде нужен ещё один игрок.)
- It's my **turn** to **win**! (Моя очередь выигрывать!)

## Мини-практика

1. Переведи слово score — **счёт**.
2. Как будет «головоломка» на английском? — **puzzle**.
3. Переведи слово turn — **ход, очередь**.
4. Как по-английски «проигрывать»? — **lose**.
5. Переведи слово outdoor game — **игра на улице**.
