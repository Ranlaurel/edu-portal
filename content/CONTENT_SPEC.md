# Формат контента темы (lesson.md + quiz.json)

Каждая тема — это папка `content/<subject>/<slug>/` с двумя файлами. Смотри готовый
эталонный пример: `content/russian/povtorenie-y-tverdyi-znak/lesson.md` и `quiz.json`
в той же папке — открой и скопируй стиль/уровень детализации.

## lesson.md

Markdown, без фронтматтера. Структура:

```
# Заголовок темы (человеко-читаемый, не служебное название)

## Подраздел правила 1
Объяснение простым языком для 6-классника. Без "воды" — сразу суть правила,
2-4 примера с выделением жирным ключевой части (**корень**, **суффикс** и т.п.).

## Подраздел правила 2
...

## Мини-практика
Пронумерованный список 4-6 заданий в формате "вопрос — **ответ** (краткое объяснение)".
```

Объём: 300-500 слов на тему (не считай слова, ориентируйся по объёму эталона).
Никакой "воды" — не растягивай, не повторяй одно и то же разными словами, не пиши
"давайте разберёмся" и общие вводные фразы. Сразу к правилу, всегда с конкретными
примерами (для математики — с числами и вычислениями, не абстрактно).

Для математики: формулы пиши текстом (используй ×, ÷, ², ³, √ где уместно — обычные
юникод-символы, НЕ LaTeX/MathJax, рендер простой markdown без формул).

## quiz.json

Ровно 8-10 вопросов. **Обязательно используй все 5 типов минимум по разу** за тему,
остальные вопросы — на усмотрение (обычно 2-3 single, 1-2 multiple, 1-2 dropdown,
1-2 fill_blank, 1 matching). Формат:

```json
{
  "questions": [
    {
      "type": "single",
      "text": "Текст вопроса?",
      "options": [
        {"text": "вариант 1", "correct": true},
        {"text": "вариант 2", "correct": false}
      ],
      "explanation": "Почему правильный ответ именно такой — 1-2 предложения, со ссылкой на правило."
    },
    {
      "type": "multiple",
      "text": "Текст вопроса (выбери все верные варианты)",
      "options": [ ... 4-5 вариантов, 2+ correct: true ... ],
      "explanation": "..."
    },
    {
      "type": "dropdown",
      "text": "Текст с пропуском (реализуется как выпадающий список)",
      "options": [ ... 2-3 варианта, ровно 1 correct: true ... ],
      "explanation": "..."
    },
    {
      "type": "fill_blank",
      "text": "Впиши только пропущенную букву/слово: ...",
      "answer": "правильный_ответ",
      "explanation": "..."
    },
    {
      "type": "matching",
      "text": "Соедини пары: ...",
      "pairs": [
        {"left": "...", "right": "..."},
        {"left": "...", "right": "..."},
        {"left": "...", "right": "..."},
        {"left": "...", "right": "..."}
      ],
      "explanation": "..."
    }
  ]
}
```

Требования к вопросам:
- Все ответы должны быть **фактически верными** (математика: проверь вычисления
  вручную перед записью; русский язык: проверь по правилу из lesson.md).
  Вопросы должны прямо опираться на материал lesson.md той же темы, не выдумывай
  новых правил, которых нет в уроке.
- `explanation` пишется всегда, объясняет ПОЧЕМУ ответ верный (правило, а не просто
  "потому что так правильно").
- Для `fill_blank` ответ короткий (одна буква или одно слово), без вариативности
  формулировки — иначе сравнение (без учёта регистра) не совпадёт. Если возможны
  разные написания, добавь `"accepted": ["вар1", "вар2"]` вместо/вместе с `answer`.
- Для `matching` — 4 пары, `left` и `right` соответствуют по смыслу; порядок
  `right` в интерфейсе перемешивается автоматически, порядок `left` — нет.
- `single`/`multiple`/`dropdown` — не делай явно "угадываемых" вариантов (все
  варианты должны быть правдоподобны для того, кто не выучил тему).

## Английский язык — отличия от русского/математики

Аудитория — русскоязычный 6-классник, изучающий английский. Смотри эталон:
`content/english/semya-chleny-prazdniki/lesson.md` и `quiz.json`.

**lesson.md**: та же структура (заголовок → подразделы правил → мини-практика), но
каждая тема — это связка **лексика (тема) + один грамматический пункт**, а не только
грамматика:

```
# Заголовок темы (по-русски)

## Слова по теме
Таблица или список: английское слово — перевод. 10-15 слов по теме урока.

## Грамматика: <название явления> (например, Present Simple для описания привычек)
Объяснение правила **по-русски**, формула образования, 3-4 примера предложений
на английском с переводом в скобках.

## Мини-практика
4-6 заданий вида "переведи / вставь слово / составь предложение — **ответ**".
```

Грамматика для 6 класса (используй уместное к теме, не изобретай сложнее):
Present Simple/Continuous, Past Simple, Future (will/going to), модальные глаголы
(must/have to/should/can), степени сравнения прилагательных, some/any/no,
исчисляемые/неисчисляемые существительные, притяжательный падеж ('s), артикли
(a/an/the), предлоги места и времени, вопросительные слова, there is/there are.

**quiz.json**: та же схема (8-10 вопросов, все 5 типов), но смысл типов другой:
- `single`/`multiple` — выбор правильного перевода слова, правильной грамматической
  формы или ответ на понимание короткого текста/диалога.
- `dropdown` — выбор верной формы глагола/слова в предложении с пропуском.
- `fill_blank` — вписать английское слово или грамматическую форму (`answer` —
  само английское слово/форма, не перевод).
- `matching` — пары "английское слово — русский перевод" (4 пары).

Объяснения (`explanation`) тоже по-русски.

## Устные предметы (биология, география, история, литература) — отличия

Это предметы с пересказом/рассказом, а не формулой+примером. Компрессия здесь
значительно мягче, чем у русского/математики/английского — тем ближе к реальному
числу параграфов учебника, не сжимай агрессивно. Смотри эталон:
`content/biology/obschie-priznaki-rasteniy/lesson.md` и `quiz.json`.

**lesson.md**: структура та же (заголовок → подразделы → мини-практика), но
содержание — факты, определения, описание процессов/событий/произведений, а не
правило с исключениями:

```
# Заголовок темы

## Подраздел 1
Факты, определения, описание. Ключевые термины/имена/даты — **жирным**.
Если это литература — краткий пересказ сюжета + 1-2 цитаты + о чём произведение.
Если это история — что произошло, когда, кто участвовал, почему это важно.
Если биология/география — определение явления/объекта, его строение/процесс,
значение.

## Подраздел 2
...

## Мини-практика
4-6 заданий: "объясни своими словами / перечисли / когда произошло — **ответ**".
```

**quiz.json**: та же схема (8-10 вопросов, все 5 типов), но смысл:
- `single`/`multiple` — факты, даты, причины и следствия, понимание прочитанного
  (для литературы — сюжет, характеристика персонажа).
- `dropdown` — выбор верного термина/имени/даты из похожих вариантов.
- `fill_blank` — вписать термин, имя, дату, число.
- `matching` — термин↔определение, событие↔дата, деятель↔достижение, произведение↔автор
  (смотря что уместно теме).

Объяснения (`explanation`) по-русски, с фактической опорой на lesson.md.
