# Профессии: часть 2

## Слова по теме

| Английский | Перевод |
|---|---|
| farmer | фермер |
| pilot | пилот |
| singer | певец |
| builder | строитель |
| shop assistant | продавец |
| vet | ветеринар |

## Грамматика: want to be / work as

Чтобы сказать, кем человек хочет стать: **want to be a/an + профессия**.
Чтобы сказать, кем человек работает (другой способ): **work as + профессия**.

- I **want to be a pilot**. (Я хочу стать **пилотом**.)
- They **work as** builders. (Они **работают** строителями.)
- My aunt **is a vet**. (Моя тётя **ветеринар**.)

## Мини-практика

1. Как сказать «я хочу стать пилотом»? — **I want to be a pilot**.
2. Переведи слово vet — **ветеринар**.
3. Как будет «продавец» на английском? — **shop assistant**.
4. Составь предложение: моя тётя — фермер. — **My aunt is a farmer**.
5. Переведи слово singer — **певец**.
