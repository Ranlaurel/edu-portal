# Транспорт

## Слова по теме

| Английский | Перевод |
|---|---|
| car | машина |
| bus | автобус |
| train | поезд |
| plane | самолёт |
| bike | велосипед |
| tram | трамвай |
| taxi | такси |
| ship | корабль |
| metro / underground | метро |
| on foot | пешком |

## Грамматика: предлог by для транспорта

Чтобы сказать, каким способом человек передвигается, используем предлог **by** + вид транспорта (без артикля).

Формула: **go/travel + by + транспорт**.

- I go to school **by bus**. (Я езжу в школу **на автобусе**.)
- She travels **by train**. (Она путешествует **на поезде**.)
- We go **by plane**. (Мы летим **на самолёте**.)

Исключение: если человек идёт пешком, говорим **on foot** (без by).

- My friend goes to school **on foot**. (Мой друг ходит в школу **пешком**.)

## Мини-практика

1. Как сказать «на машине»? — **by car**.
2. Впиши предлог: I go to school ___ bus. — **by**.
3. Переведи слово ship — **корабль**.
4. Как будет «пешком» на английском? — **on foot** (исключение, без by).
5. Составь предложение: она путешествует на поезде. — **She travels by train**.
6. Переведи слово underground — **метро**.
