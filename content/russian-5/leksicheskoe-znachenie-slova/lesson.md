# Слово и его лексическое значение

## Что такое лексическое значение

**Лексическое значение** слова — это то, что оно обозначает, какой смысл в нём заключён. Например, слово **берёза** обозначает лиственное дерево с белым стволом, а слово **бежать** — быстро передвигаться на ногах.

Лексическое значение слова объясняется в **толковом словаре**. Там же указывается, как слово пишется и в каких значениях употребляется.

Пример словарной статьи: **Портфель** — сумка для ношения книг, тетрадей, бумаг.

## Лексическое и грамматическое значение

У каждого слова есть два значения:

- **лексическое** — конкретный смысл (что слово называет);
- **грамматическое** — общие признаки слова как части речи (число, род, падеж, время и т.п.).

Сравним слова **дом** и **дома**. Лексическое значение у них одно и то же — «здание для жилья». А грамматическое значение разное: **дом** — единственное число, именительный падеж; **дома** — множественное число (или родительный падеж единственного числа).

## Как определить лексическое значение

Чтобы понять значение незнакомого слова, можно:

1. посмотреть в толковом словаре;
2. догадаться по контексту — по другим словам в предложении;
3. подобрать похожее по смыслу слово (синоним).

Пример: «Мальчик шёл по **тропинке** через лес». Из контекста понятно, что **тропинка** — это узкая дорожка.

Некоторые слова имеют несколько лексических значений — они называются **многозначными**, о них пойдёт речь в следующей теме.

## Мини-практика

1. Объясни лексическое значение слова **карандаш**. — **предмет для письма и рисования, тонкая палочка с грифелем внутри деревянной или пластиковой оболочки**.
2. Найди в толковом словаре значение слова **компас**. — **прибор для определения сторон света**.
3. Определи по контексту значение слова **опушка** в предложении «Заяц выбежал на опушку леса». — **край леса, граница леса с полем**.
4. Чем лексическое значение слова отличается от грамматического? — **лексическое — это конкретный смысл слова, грамматическое — его признаки как части речи (число, род, падеж и т.д.)**.
5. Подбери слово по его лексическому значению: «водитель транспортного средства». — **шофёр** (или **водитель**).
6. В каком словаре объясняется лексическое значение слов? — **в толковом словаре**.
