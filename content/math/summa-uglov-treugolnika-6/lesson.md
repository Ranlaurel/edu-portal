# Сумма углов треугольника

## Теорема о сумме углов
В любом треугольнике сумма трёх углов равна **180°**. Это верно для любого треугольника — остроугольного, прямоугольного или тупоугольного.
Если известны два угла треугольника, третий находят вычитанием их суммы из 180°.
Пример: углы треугольника 50° и 70°. Третий угол: 180° − 50° − 70° = 180° − 120° = **60°**.
Пример: углы треугольника 90° и 35° (прямоугольный треугольник). Третий угол: 180° − 90° − 35° = **55°**.

## Углы равнобедренного и равностороннего треугольника
В равностороннем треугольнике все углы равны, а их сумма — 180°, значит каждый угол равен 180° ÷ 3 = **60°**.
В равнобедренном треугольнике углы при основании равны между собой. Если угол при вершине 40°, то на два угла при основании остаётся 180° − 40° = 140°, каждый из них: 140° ÷ 2 = **70°**.
Пример: равнобедренный треугольник, угол при основании 65°. Второй угол при основании тоже 65°. Угол при вершине: 180° − 65° − 65° = **50°**.

## Мини-практика
1. Углы треугольника 45° и 95°. Найди третий угол — **40°** (180° − 45° − 95° = 40°).
2. Прямоугольный треугольник, один из острых углов 28°. Найди второй острый угол — **62°** (90° сумма острых углов, 90° − 28° = 62°).
3. Равносторонний треугольник. Чему равен каждый угол — **60°** (180° ÷ 3 = 60°).
4. Равнобедренный треугольник, угол при вершине 100°. Найди углы при основании — **по 40°** (180° − 100° = 80°, 80° ÷ 2 = 40°).
5. Углы треугольника 60°, 60° и x. Найди x — **60°** (180° − 60° − 60° = 60°, треугольник равносторонний).
6. Равнобедренный треугольник, угол при основании 72°. Найди угол при вершине — **36°** (180° − 72° − 72° = 36°).
