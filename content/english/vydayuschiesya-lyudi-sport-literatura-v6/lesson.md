# Выдающиеся люди: спорт и литература (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| author | автор |
| writer | писатель |
| novel | роман |
| poem | стихотворение |
| athlete | спортсмен |
| champion | чемпион |
| achieve | достигать |
| win | побеждать |
| medal | медаль |
| competition | соревнование |
| become | становиться |
| record | рекорд |
| talent | талант |
| bestseller | бестселлер |
| team | команда |

## Примеры предложений

- The famous **author** wrote a **bestseller** about a young **athlete**. (Известный
автор написал бестселлер о молодом спортсмене.)
- She has a great **talent** for writing **poems**. (У неё большой талант к
написанию стихотворений.)
- Our **team** won a gold **medal** at the **competition**. (Наша команда выиграла
золотую медаль на соревновании.)

## Мини-практика

1. Переведи слово achieve — **достигать**.
2. Как будет «писатель» на английском? — **writer**.
3. Переведи слово record — **рекорд**.
4. Как по-английски «соревнование»? — **competition**.
5. Переведи слово bestseller — **бестселлер**.
