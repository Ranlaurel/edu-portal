# Морфемный разбор слова

## Что такое морфемный разбор

**Морфемный разбор** (разбор слова по составу) — это выделение в слове всех значимых частей: **окончания**, **основы**, **корня**, **приставки** и **суффикса**. Каждая часть слова называется морфемой.

**Окончание** — изменяемая часть слова, которая образует форму слова и связывает слова в предложении (стол, стол**а**, стол**у**). **Основа** — часть слова без окончания (в слове стол**а** основа — стол-). **Корень** — общая часть родственных слов, хранящая главное значение.

## Порядок разбора слова по составу

1. Найти **окончание**: изменить слово по числам или падежам, та часть, что меняется — окончание. У неизменяемых слов (наречий, некоторых существительных) окончания нет.
2. Выделить **основу** — всё, что осталось без окончания.
3. Найти **корень**: подобрать однокоренные слова, общая часть — корень.
4. Найти **приставку** — часть перед корнем (если есть).
5. Найти **суффикс** — часть после корня, перед окончанием (если есть).

Пример разбора слова **подснежники**: окончание -и (подснежник**и** — подснежник**а**, меняется), основа подснежник-, корень -снеж- (снег, снежный), приставка под-, суффикс -ник-.

## Примеры полного разбора

**Пришкольный**: приставка при-, корень -школь-, суффикс -н-, окончание -ый. Проверка корня: школа, школьник — общая часть -школь-.

**Перелесок**: приставка пере-, корень -лес-, суффикс -ок, окончание нулевое (у слова нет буквы после -ок, но окончание всё равно есть — оно нулевое, сравни: перелеск**а**, где окончание -а появляется).

**Бегущий**: корень -бег-, суффикс -ущ- (образует форму от глагола бежать), окончание -ий.

## Мини-практика

1. Раздели на морфемы слово **дождик** — корень дожд-, суффикс -ик-, окончание нулевое.
2. Выдели основу в слове **зимняя** — основа **зимн-** (без окончания -яя).
3. Найди корень в словах лес, лесник, лесной — общая часть **лес-**.
4. Разбери по составу слово **подорожник** — приставка **под-**, корень **-дорож-** (дорога), суффикс **-ник-**, окончание нулевое.
5. Есть ли окончание у слова **вчера**? — **нет**, это неизменяемое наречие.
6. Разбери по составу слово **перестройка** — приставка **пере-**, корень **-стро-** (строить), суффикс **-йк-**, окончание **-а**.
