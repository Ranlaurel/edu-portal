# Город: места

## Слова по теме

| Английский | Перевод |
|---|---|
| street | улица |
| park | парк |
| hospital | больница |
| library | библиотека |
| museum | музей |
| bridge | мост |
| square | площадь |
| bank | банк |
| station | вокзал, станция |

## Грамматика: is/are с местами города

Чтобы сказать, что где-то есть какое-то место, используем **is** (одно место) или **are** (несколько мест).

- The park **is** big. (Парк большой.)
- There **is** a museum in our city. (В нашем городе есть музей.)

## Мини-практика

1. Переведи слово library — **библиотека**.
2. Как будет «мост» на английском? — **bridge**.
3. Переведи слово square — **площадь**.
4. Как будет «вокзал» на английском? — **station**.
5. Переведи слово hospital — **больница**.
