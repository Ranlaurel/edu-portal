# Покупки: одежда и обувь (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| clothes | одежда |
| shoes | обувь |
| T-shirt | футболка |
| jeans | джинсы |
| jacket | куртка |
| dress | платье |
| skirt | юбка |
| trainers / sneakers | кроссовки |
| boots | ботинки/сапоги |
| size | размер |
| colour | цвет |
| try on | примерять |
| shop assistant | продавец |
| shop window | витрина |
| price | цена |

## Примеры предложений

- These **jeans** are the wrong **size** for me. (Эти джинсы не моего размера.)
- I like the **colour** of that **dress** in the **shop window**. (Мне нравится цвет
того платья на витрине.)
- Can I **try on** these **boots**, please? (Можно примерить эти ботинки, пожалуйста?)

## Мини-практика

1. Переведи слово price — **цена**.
2. Как будет «продавец» на английском? — **shop assistant**.
3. Переведи слово try on — **примерять**.
4. Как по-английски «кроссовки»? — **trainers / sneakers**.
5. Переведи слово shop window — **витрина**.
