# Семья и внешность: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| family | семья |
| mother / father | мама / папа |
| brother / sister | брат / сестра |
| tall | высокий |
| short | низкий (невысокий) |
| young | молодой |
| old | старый |
| hair | волосы |
| eyes | глаза |
| curly | кудрявый |
| straight | прямой (о волосах) |
| beautiful | красивый |

Примеры:
- My **family** is big. (Моя семья большая.)
- My sister has got **curly** hair. (У моей сестры кудрявые волосы.)
- My grandfather is **tall** and **old**. (Мой дедушка высокий и старый.)

## Мини-практика

1. Переведи слово curly — **кудрявый**.
2. Как по-английски «высокий»? — **tall**.
3. Переведи слово eyes — **глаза**.
4. Как сказать «низкий (невысокий)»? — **short**.
5. Переведи слово straight — **прямой (о волосах)**.
6. Переведи слово beautiful — **красивый**.
