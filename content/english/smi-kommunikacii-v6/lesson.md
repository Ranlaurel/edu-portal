# Средства массовой информации (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| media | СМИ, медиа |
| newspaper | газета |
| magazine | журнал |
| channel | канал |
| news | новости |
| article | статья |
| journalist | журналист |
| radio | радио |
| social media | социальные сети |
| advertisement | реклама |
| information | информация |
| interview | интервью |
| broadcast | трансляция, вещание |
| headline | заголовок |
| website | сайт |

## Мини-практика

1. Переведи слово journalist — **журналист**.
2. Переведи слово headline — **заголовок**.
3. Переведи фразу «социальные сети» — **social media**.
4. Как будет «трансляция» на английском? — **broadcast**.
5. Чем newspaper отличается от magazine? — **newspaper — ежедневная газета с новостями, magazine — журнал (реже выходит, разные темы)**.
6. Переведи слово advertisement — **реклама**.
