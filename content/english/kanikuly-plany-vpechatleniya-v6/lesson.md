# Каникулы: планы и впечатления — слова

## Слова по теме

| Английский | Перевод |
|---|---|
| holiday / vacation | каникулы, отпуск |
| visit | посещать |
| relax | отдыхать, расслабляться |
| enjoy | наслаждаться |
| amazing | потрясающий |
| boring | скучный |
| exciting | увлекательный |
| terrible | ужасный |
| impression | впечатление |
| memory | воспоминание |
| stay (at/in) | останавливаться (где-то) |
| swim | плавать |
| walk | гулять, идти пешком |
| take photos | фотографировать |
| have fun | веселиться |

## Примеры предложений

- We had an **amazing holiday** by the sea. (У нас были потрясающие каникулы у моря.)
- The film was so **boring** that I fell asleep. (Фильм был таким скучным, что я заснул(а).)
- I love taking **photos** and I have a lot of good **memories**. (Я люблю фотографировать, и у меня много хороших воспоминаний.)
- We **stayed at** a small hotel and **had fun** every day. (Мы останавливались в маленьком отеле и веселились каждый день.)

## Мини-практика

1. Переведи слово exciting — **увлекательный**.
2. Переведи impression — **впечатление**.
3. Как будет «наслаждаться» на английском? — **enjoy**.
4. Как по-английски «останавливаться (где-то)»? — **stay**.
5. Переведи предложение: We had fun at the beach. — **Мы веселились на пляже.**
