# Части тела

## Слова по теме

| Английский | Перевод |
|---|---|
| head | голова |
| arm | рука (от плеча) |
| hand | кисть руки |
| leg | нога |
| foot | ступня |
| back | спина |
| stomach | живот |
| tooth | зуб |
| ill / sick | больной |
| a cold | простуда |
| doctor | врач |
| hurt | болеть (о части тела) |

## Мини-практика

1. Переведи слово stomach — **живот**.
2. Переведи слово tooth — **зуб**.
3. Как по-английски «ступня»? — **foot**.
4. Переведи слово back — **спина**.
5. Как по-английски «больной»? — **ill / sick**.
6. Переведи слово doctor — **врач**.
