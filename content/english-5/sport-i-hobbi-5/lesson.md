# Спорт и хобби

## Слова по теме

| Английский | Перевод |
|---|---|
| football | футбол |
| basketball | баскетбол |
| swimming | плавание |
| running | бег |
| chess | шахматы |
| dancing | танцы |
| drawing | рисование |
| reading | чтение |
| play | играть |
| go | ходить, заниматься |
| favourite | любимый |
| team | команда |

## Грамматика: play / go / do в хобби

С видами спорта, где играют с мячом, используется глагол **play**: play football, play basketball, play chess.

С хобби, оканчивающимися на **-ing** (плавание, бег, танцы), используется глагол **go**: go swimming, go running, go dancing.

С другими занятиями используется **do**: do sport, do exercises.

- I **play** football every weekend. (Я **играю** в футбол каждые выходные.)
- My sister **goes swimming** twice a week. (Моя сестра **плавает** два раза в неделю.)
- He **likes drawing**. (Он **любит рисовать**.)

Не забывай окончание **-s** для he/she/it в Present Simple: she **plays**, he **goes**.

## Мини-практика

1. Как сказать «я играю в шахматы»? — **I play chess**.
2. Впиши глагол: My brother ___ swimming every summer (he — go). — **goes** (goes swimming).
3. Переведи слово favourite — **любимый**.
4. Как будет «рисование» на английском? — **drawing**.
5. Составь предложение: моя сестра любит танцевать. — **My sister likes dancing**.
6. Впиши глагол: We ___ basketball on Fridays. — **play** (play basketball).
