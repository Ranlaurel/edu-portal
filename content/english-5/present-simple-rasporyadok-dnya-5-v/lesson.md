# Распорядок дня: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| get up | вставать |
| wash | умываться / мыть |
| have breakfast | завтракать |
| go to school | идти в школу |
| do homework | делать домашнее задание |
| have lunch | обедать |
| have dinner | ужинать |
| go to bed | ложиться спать |
| every day | каждый день |
| usually | обычно |
| always | всегда |
| never | никогда |

## Мини-практика

1. Переведи фразу get up — **вставать**.
2. Переведи фразу do homework — **делать домашнее задание**.
3. Как по-английски «ложиться спать»? — **go to bed**.
4. Переведи слово never — **никогда**.
5. Как по-английски «обедать»? — **have lunch**.
6. Переведи слово usually — **обычно**.
