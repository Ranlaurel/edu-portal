# Задание 8. Степени и корни

В задании 8 нужно вычислить значение выражения со степенями или корнями. Ответ — целое число или конечная десятичная дробь.

## Свойства степеней
| Правило | Пример |
|---|---|
| aᵐ · aⁿ = aᵐ⁺ⁿ | 3² · 3³ = 3⁵ = 243 |
| aᵐ ÷ aⁿ = aᵐ⁻ⁿ | 5⁷ ÷ 5⁵ = 5² = 25 |
| (aᵐ)ⁿ = aᵐⁿ | (2³)² = 2⁶ = 64 |
| a⁰ = 1 | 17⁰ = 1 |
| a⁻ⁿ = 1 / aⁿ | 2⁻² = 1/4 = 0,25 |

Сначала упрощай буквенное выражение по свойствам, потом подставляй число — так меньше вычислений.

## Свойства корней
- √(a · b) = √a · √b, поэтому √3 · √12 = √36 = **6**.
- √(a²) = **|a|**: √((−4)²) = 4.
- (√a)² = a: (√7)² = **7**.
- Разность квадратов с корнями: (√11 − 3)(√11 + 3) = 11 − 9 = **2**.

## Корень из степени
√(2⁶) = 2³ = **8**, потому что (2³)² = 2⁶. Показатель делится пополам.

## Частые ошибки
- (−3)² = 9, а −3² = −9: минус без скобок не возводится в степень.
- √(9 + 16) = √25 = 5, а не 3 + 4 = 7: корень из суммы не равен сумме корней.

## Мини-практика
1. 2⁵ · 2⁻² — **8**.
2. √2 · √32 — **8**.
3. (√6 − 1)(√6 + 1) — **5**.
4. 10⁻² — **0,01**.
