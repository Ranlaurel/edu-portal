# Свойства сложения

## Переместительное свойство
От перестановки слагаемых сумма не меняется: **a + b = b + a**.
Пример: 15 + 27 = 42 и 27 + 15 = 42 — результат один и тот же.
Это свойство помогает удобнее считать: если одно слагаемое круглое число, его удобно писать первым.
Пример: 8 + 100 удобнее посчитать как 100 + 8 = **108**.

## Сочетательное свойство
Чтобы сложить сумму двух чисел с третьим числом, можно к первому числу прибавить сумму второго и третьего: **(a + b) + c = a + (b + c)**.
Это свойство позволяет группировать слагаемые так, чтобы считать было удобнее — например, сначала складывать числа, которые в сумме дают круглое число.
Пример: 37 + 15 + 5 = 37 + (15 + 5) = 37 + 20 = **57**.
Пример: 24 + 76 + 8 = (24 + 76) + 8 = 100 + 8 = **108**.

## Сложение с нулём
При сложении числа с нулём сумма равна этому же числу: **a + 0 = a**.
Пример: 234 + 0 = **234**.
Используя переместительное и сочетательное свойства вместе, при сложении нескольких чисел их можно переставлять и группировать любым удобным способом.
Пример: 5 + 128 + 15 + 2 = (5 + 15) + (128 + 2) = 20 + 130 = **150**.

## Мини-практика
1. Примени переместительное свойство: 34 + 66 — посчитай удобным способом — **100** (34 + 66 = 66 + 34 = 100).
2. Сгруппируй удобно: 45 + 18 + 2 — **65** (45 + (18 + 2) = 45 + 20 = 65).
3. Найди сумму: 156 + 0 — **156** (сложение с нулём не меняет число).
4. Сгруппируй удобно: 7 + 93 + 13 — **113** ((7 + 93) + 13 = 100 + 13 = 113).
5. Как называется свойство a + b = b + a? — **переместительное**.
6. Найди значение удобным способом: 25 + 149 + 75 — **249** ((25 + 75) + 149 = 100 + 149 = 249).
