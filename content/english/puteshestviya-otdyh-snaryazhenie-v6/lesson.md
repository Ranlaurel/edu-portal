# Путешествия: виды отдыха и снаряжение — слова

## Слова по теме

| Английский | Перевод |
|---|---|
| trip | поездка |
| journey | путешествие (обычно долгое) |
| travel | путешествовать |
| tourist | турист |
| luggage / baggage | багаж |
| suitcase | чемодан |
| backpack | рюкзак |
| tent | палатка |
| passport | паспорт |
| ticket | билет |
| beach holiday | пляжный отдых |
| camping | отдых с палатками |
| sightseeing | осмотр достопримечательностей |
| abroad | за границей |
| souvenir | сувенир |

## Примеры предложений

- I packed my **suitcase** and **backpack** for the **trip**. (Я собрал(а) чемодан и рюкзак для поездки.)
- We are going **abroad** for a **beach holiday**. (Мы едем за границу на пляжный отдых.)
- Don't forget your **passport** and **ticket**! (Не забудь паспорт и билет!)
- We bought a nice **souvenir** after **sightseeing**. (Мы купили красивый сувенир после осмотра достопримечательностей.)

## Мини-практика

1. Переведи слово luggage — **багаж**.
2. Как будет «билет» по-английски? — **ticket**.
3. Переведи sightseeing — **осмотр достопримечательностей**.
4. Как по-английски «отдых с палатками»? — **camping**.
5. Переведи предложение: We travelled abroad last year. — **Мы путешествовали за границей в прошлом году.**
