# Еда и напитки: some / any

## Слова по теме

| Английский | Перевод |
|---|---|
| some | несколько/немного (в утверждениях) |
| any | несколько/немного (в вопросах и отрицаниях) |
| fridge | холодильник |
| a lot of | много |

## Грамматика: some / any

**Some** используем в утвердительных предложениях, **any** — в вопросах и отрицаниях.

- There **is some** milk in the fridge. (В холодильнике есть немного молока.)
- I've got **some** apples. (У меня есть яблоки.)
- **Is there any** juice? (Есть сок?)
- There **isn't any** bread. (Хлеба нет.)

Правило работает одинаково и с исчисляемыми существительными во множественном числе (**apples, eggs**), и с неисчисляемыми (**milk, bread, sugar**).

Исключение: если в вопросе мы предлагаем угощение или о чём-то просим, используем **some**, а не any.
- Would you like **some** juice? (Хочешь сока?)

## Мини-практика

1. Вставь: There is ___ milk in the fridge. — **some**.
2. Вставь: Is there ___ juice? — **any**.
3. Составь отрицание: There is some bread. → **There isn't any bread.**
4. Переведи: У меня есть немного яблок. — **I've got some apples.**
5. Вставь: Would you like ___ tea? (предложение угощения) — **some**.
