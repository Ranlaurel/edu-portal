# Притяжательный падеж ('s)

## Слова по теме

| Английский | Перевод |
|---|---|
| dog | собака |
| cat | кошка |
| friend | друг |
| name | имя |
| book | книга |
| bag | сумка |
| toy | игрушка |
| teacher | учитель |
| room | комната |
| bike | велосипед |

## Грамматика: притяжательный падеж ('s)

Притяжательный падеж показывает, кому что принадлежит. Формула: **имя/сущ. в ед.ч. + 's**.

- This is Ann**'s** bag. (Это сумка **Энн**.)
- My friend**'s** dog is small. (Собака **моего друга** маленькая.)
- The teacher**'s** book is on the table. (Книга **учителя** на столе.)

Если существительное во множественном числе уже оканчивается на **-s**, добавляем только апостроф: my friend**s'** room (комната моих друзей).

Если слово во множественном числе не оканчивается на -s (например, children), добавляем 's как обычно: the children**'s** toys (игрушки детей).

## Мини-практика

1. Как сказать «велосипед Тома»? — **Tom's bike** (притяжательный падеж).
2. Впиши апостроф: my friend___ dog (собака моего друга). — **'s** (my friend's dog).
3. Переведи слово toy — **игрушка**.
4. Как сказать «комната моих друзей» (мн. число, оканчивается на -s)? — **my friends' room**.
5. Составь предложение с 's: имя учителя — **the teacher's name**.
6. Как будет «сумка» на английском? — **bag**.
