# Чередование звуков

## Что такое чередование

Чередование — это замена одного звука другим в одном и том же корне при изменении слова или образовании новых слов. Буква на письме при этом тоже меняется. Корень остаётся «тем же самым» по значению, хотя пишется немного иначе.

Частые виды чередований согласных:
- **г // ж**: бере**г** — бере**ж**ёт, дру**г** — дру**ж**ба;
- **к // ч**: ру**к**а — ру**ч**ка, пе**к**у — пе**ч**ёт;
- **х // ш**: пу**х** — пу**ш**истый, ти**х**о — ти**ш**е;
- **д // ж**: хо**д**ить — хо**ж**у, ро**д**ить — ро**ж**у;
- **т // ч**: све**т**ить — све**ч**а, хо**т**еть — хо**ч**у;
- **з // ж**: моро**з** — моро**ж**еное.

## Чередование гласных

Гласные тоже чередуются: **о // а** в корнях с чередованием (гор- // гар-, раст- // рос-): за**г**а**р** — за**г**о**р**ать; **е // и**: соб**и**рать — соб**е**рёт.

Чередование помогает объяснить, почему в родственных словах пишутся разные буквы, хотя корень один и тот же: дру**г** и дру**ж**ба — оба слова однокоренные, но конечная согласная корня меняется перед разными суффиксами.

## Мини-практика

1. Какое чередование в паре «бере**г** — бере**ж**ёт»? — **г // ж**.
2. Подбери слово с чередованием к // ч от «рука» — ру**чк**а.
3. Какое чередование в паре «ходить — хожу»? — **д // ж**.
4. Найди чередование в паре «пух — пушистый» — **х // ш**.
5. Приведи пример чередования гласных о // а — заг**а**р — заг**о**рать.
6. Почему в словах «друг» и «дружба» разные согласные на конце корня? — из-за **чередования г // ж**.
