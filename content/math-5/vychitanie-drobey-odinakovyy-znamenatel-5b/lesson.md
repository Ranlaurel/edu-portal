# Вычитание дробей с одинаковым знаменателем

## Правило вычитания
Чтобы вычесть из одной дроби другую с таким же знаменателем, нужно вычесть числители, а знаменатель оставить без изменений.

Пример: 5/7 − 2/7 = (5 − 2)/7 = **3/7**.

Пример: 8/9 − 3/9 = (8 − 3)/9 = **5/9**.

Пример: 7/8 − 7/8 = (7 − 7)/8 = 0/8 = **0**. Если числители равны, результат равен нулю.

## Вычитание из целого числа
Чтобы вычесть дробь из целого числа 1, представляют 1 как дробь с тем же знаменателем (например, 1 = 6/6), а затем вычитают числители.

Пример: 1 − 2/6 = 6/6 − 2/6 = (6 − 2)/6 = **4/6**.

Пример: 1 − 5/9 = 9/9 − 5/9 = (9 − 5)/9 = **4/9**.

Если нужно вычесть дробь из смешанного числа с той же дробной частью, вычитают дробные части отдельно: 3 1/5 − 4/5 сначала занимают у целой части одну единицу (1 = 5/5), получают 2 6/5 − 4/5 = 2 2/5.

## Мини-практика
1. Вычти: 6/7 − 2/7 — **4/7** (6 − 2 = 4, знаменатель 7 не меняется).
2. Вычти: 9/10 − 3/10 — **6/10** (9 − 3 = 6, знаменатель 10).
3. Вычти: 5/5 − 3/5 — **2/5** (5 − 3 = 2, знаменатель 5).
4. Вычисли: 1 − 3/8 — **5/8** (1 = 8/8, 8 − 3 = 5).
5. Вычти: 7/12 − 7/12 — **0** (числители равны, 7 − 7 = 0).
6. У Кати было 9/11 ленты, она отрезала 4/11. Сколько ленты осталось? — **5/11** (9 − 4 = 5).
