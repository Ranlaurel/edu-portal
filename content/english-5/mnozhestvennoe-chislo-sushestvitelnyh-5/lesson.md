# Множественное число существительных

## Слова по теме

| Английский | Перевод |
|---|---|
| box | коробка |
| child | ребёнок |
| man | мужчина |
| woman | женщина |
| foot | нога (ступня) |
| tooth | зуб |
| pen | ручка |
| apple | яблоко |
| city | город |
| baby | младенец |

## Грамматика: множественное число существительных

Чаще всего к слову просто добавляется **-s**: pen → pen**s**, apple → apple**s**.

Если слово оканчивается на **-s, -ss, -sh, -ch, -x**, добавляется **-es**: box → box**es**, bus → bus**es**.

Если слово оканчивается на **согласную + y**, буква y меняется на **i** и добавляется **-es**: city → cit**ies**, baby → bab**ies**. Но если перед y стоит гласная, просто добавляем -s: boy → boy**s**.

Есть слова-исключения с особым множественным числом:
- child → **children** (дети)
- man → **men** (мужчины)
- woman → **women** (женщины)
- foot → **feet** (ноги)
- tooth → **teeth** (зубы)

## Мини-практика

1. Как будет «коробки» во множественном числе? — **boxes** (оканчивается на -x → +es).
2. Впиши множественное число: city → ___. — **cities** (согласная + y → ies).
3. Переведи слово tooth — **зуб**.
4. Как будет «дети» во множественном числе? — **children** (исключение).
5. Составь множественное число слова apple — **apples**.
6. Как будет «мужчины» во множественном числе? — **men** (исключение).
