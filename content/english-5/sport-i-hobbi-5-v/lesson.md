# Спорт и хобби: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| football | футбол |
| basketball | баскетбол |
| swimming | плавание |
| running | бег |
| chess | шахматы |
| dancing | танцы |
| drawing | рисование |
| reading | чтение |
| favourite | любимый |
| team | команда |

## Грамматика: like/love + -ing

Чтобы сказать, что человеку нравится занятие, используем **like/love + глагол с -ing**.

- I **like reading**. (Мне **нравится читать**.)
- She **loves dancing**. (Она **обожает танцевать**.)

## Мини-практика

1. Переведи слово chess — **шахматы**.
2. Как будет «рисование» на английском? — **drawing**.
3. Переведи слово favourite — **любимый**.
4. Составь предложение: мне нравится плавание. — **I like swimming**.
5. Переведи слово team — **команда**.
