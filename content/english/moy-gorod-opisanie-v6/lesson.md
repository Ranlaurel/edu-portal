# Мой город: описание (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| town | город (небольшой) |
| city | город (крупный) |
| population | население |
| famous for | знаменитый чем-то |
| modern | современный |
| ancient | древний |
| capital | столица |
| centre | центр |
| suburb | пригород |
| building | здание |
| habitant / resident | житель |
| industry | промышленность |
| beautiful | красивый |
| large | большой |
| small | маленький |

## Мини-практика

1. Переведи слово population — **население**.
2. Переведи слово ancient — **древний**.
3. Как будет «пригород» на английском? — **suburb**.
4. Переведи фразу «знаменит своим музеем» — **famous for its museum**.
5. Чем town отличается от city? — **town — небольшой город, city — крупный город**.
6. Переведи слово resident — **житель**.
