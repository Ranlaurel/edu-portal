# Сложение натуральных чисел

## Как складывают числа в столбик
Числа, которые складывают, называются **слагаемыми**, а результат сложения — **суммой**. Запись 4 + 3 = 7 означает: слагаемое 4, слагаемое 3, сумма 7.
Чтобы сложить многозначные числа, их записывают в столбик так, чтобы одинаковые разряды находились друг под другом (единицы под единицами, десятки под десятками и так далее). Складывают, начиная с единиц.
Если при сложении цифр в одном разряде получается число больше 9, то в этом разряде записывают только цифру единиц, а десяток переносят в следующий разряд.
Пример: 236 + 458. Единицы: 6 + 8 = 14, пишем 4, переносим 1. Десятки: 3 + 5 + 1 = 9, пишем 9. Сотни: 2 + 4 = 6, пишем 6. Получаем **694**.
Пример: 175 + 89. Единицы: 5 + 9 = 14, пишем 4, переносим 1. Десятки: 7 + 8 + 1 = 16, пишем 6, переносим 1. Сотни: 1 + 0 + 1 = 2. Получаем **264**.

## Сложение с несколькими слагаемыми
Если слагаемых больше двух, их складывают по очереди: сначала первые два, потом к результату прибавляют следующее слагаемое.
Пример: 12 + 15 + 8 = (12 + 15) + 8 = 27 + 8 = **35**.
Пример: 100 + 250 + 50 = (100 + 250) + 50 = 350 + 50 = **400**.

## Мини-практика
1. Найди сумму: 345 + 267 — **612** (5+7=12 пишем 2 перенос 1; 4+6+1=11 пишем 1 перенос 1; 3+2+1=6).
2. Найди сумму: 89 + 546 — **635** (9+6=15 пишем 5 перенос 1; 8+4+1=13 пишем 3 перенос 1; 0+5+1=6).
3. Найди сумму: 1 234 + 876 — **2 110** (4+6=10 пишем 0 перенос 1; 3+7+1=11 пишем 1 перенос 1; 2+8+1=11 пишем 1 перенос 1; 1+0+1=2).
4. Найди сумму трёх слагаемых: 25 + 40 + 15 — **80** (25+40=65, 65+15=80).
5. Как называются числа, которые складывают? — **слагаемые**.
6. Как называется результат сложения? — **сумма**.
