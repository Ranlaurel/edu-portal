# Существительные, имеющие форму только мн. или только ед. числа

## Число как признак существительного

Большинство существительных изменяются по числам: **стол — столы**, **книга — книги**, **окно — окна**. Но есть группы слов, у которых есть только одна форма числа.

## Существительные только множественного числа

Некоторые существительные употребляются **только во множественном числе**, у них нет формы единственного числа. Обычно это слова, называющие парные предметы, составные вещи, игры, некоторые отрезки времени.

Примеры: **ножницы**, **брюки**, **очки**, **ворота**, **каникулы**, **сутки**, **шахматы**, **духи**.

Нельзя сказать «одна ножница» или «один брюк» — у этих слов просто нет единственного числа.

## Существительные только единственного числа

Другие существительные употребляются **только в единственном числе**. К ним относятся:
- **вещественные** существительные (называют вещество): молоко, сахар, золото, воздух;
- **собирательные** существительные (называют множество как одно целое): детвора, листва, молодёжь, студенчество;
- **отвлечённые** (абстрактные) существительные (называют качества, чувства, действия): любовь, доброта, бег, смелость;
- некоторые **собственные** имена: Москва, Байкал.

Примеры: нельзя сказать «молока» во множественном числе в обычном значении, «листвы» тоже нет во множественном числе — это одно целое.

## Как отличить: способ проверки

Попробуй поставить слово в другое число. Если форма не образуется или меняет смысл слова (например, «воды» — уже не про вещество, а про разные виды воды) — перед тобой существительное с одной формой числа.

## Мини-практика

1. Есть ли единственное число у слова «каникулы»? — **нет** (слово только множественного числа, как и брюки, ножницы).
2. Можно ли сказать «одни очки, двое очков»? — **нет**, только «очки» (слово употребляется исключительно во множественном числе).
3. Есть ли множественное число у слова «молоко» в обычном значении? — **нет** (вещественное существительное, только единственное число).
4. К какой группе относится слово «листва»? — **собирательные существительные** (называет множество листьев как одно целое, только единственное число).
5. Определи число слова «сутки» — **только множественное число** (нельзя сказать «одна сутка»).
6. Слово «смелость» — какое по числу? — **только единственное число** (отвлечённое существительное, называет качество).
