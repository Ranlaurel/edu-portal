# Степени сравнения прилагательных

## Слова по теме

| Английский | Перевод |
|---|---|
| tall | высокий |
| short | низкий, короткий |
| big | большой |
| small | маленький |
| fast | быстрый |
| slow | медленный |
| easy | лёгкий |
| difficult | трудный |
| good | хороший |
| bad | плохой |

## Грамматика: степени сравнения прилагательных

Короткие прилагательные (1 слог, иногда 2) образуют сравнительную степень с помощью **-er**, превосходную — с помощью **-est** и слова **the**.

- tall → tall**er** → **the** tall**est**
- Tom is tall**er** than Ann. (Том выше, чем Энн.)
- Tom is **the** tall**est** in the class. (Том самый высокий в классе.)

Если прилагательное оканчивается на **-y**, буква y меняется на **i**: easy → eas**ier** → **the** eas**iest**.

Если короткое прилагательное оканчивается на одну согласную после одной гласной, эта согласная удваивается: big → big**ger** → **the** big**gest**.

Длинные прилагательные (2+ слога) образуют степени с помощью **more** и **the most**:
- difficult → **more** difficult → **the most** difficult

Есть слова-исключения:
- good → **better** → **the best**
- bad → **worse** → **the worst**

## Мини-практика

1. Как будет сравнительная степень слова fast? — **faster**.
2. Впиши превосходную степень слова big: the ___. — **the biggest** (удваивается согласная).
3. Переведи слово difficult — **трудный**.
4. Как будет сравнительная степень слова easy? — **easier** (y → i + er).
5. Как будет сравнительная степень слова good (исключение)? — **better**.
6. Составь степени сравнения слова difficult — **more difficult, the most difficult**.
