# Город: транспорт и достопримечательности (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| transport | транспорт |
| bus | автобус |
| underground / subway | метро |
| taxi | такси |
| tram | трамвай |
| bus stop | автобусная остановка |
| station | станция, вокзал |
| museum | музей |
| bridge | мост |
| square | площадь |
| park | парк |
| library | библиотека |
| church | церковь |
| monument | памятник |
| street | улица |

## Мини-практика

1. Переведи слово underground — **метро**.
2. Переведи слово monument — **памятник**.
3. Как будет «автобусная остановка» на английском? — **bus stop**.
4. Переведи слово square — **площадь**.
5. Чем tram отличается от bus? — **tram (трамвай) едет по рельсам, bus (автобус) — по дороге**.
6. Переведи слово station — **станция, вокзал**.
