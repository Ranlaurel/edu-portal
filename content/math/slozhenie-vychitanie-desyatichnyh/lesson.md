# Сложение и вычитание десятичных дробей

## Правило столбика

Десятичные дроби складывают и вычитают **столбиком**, обязательно выравнивая **запятую под запятой** (разряд под разрядом). Если не хватает цифр после запятой, дописывают нули — это не меняет значение числа.

## Сложение десятичных дробей

Пример: 3,45 + 2,7. Записываем в столбик, выравнивая запятые:
```
  3,45
+ 2,70
------
  6,15
```
Дописали 0 к 2,7, чтобы разрядов после запятой было поровну. Складываем как обычные числа: 345 + 270 = 615, значит 3,45 + 2,7 = 6,15.

Пример: 4,2 + 1,35. Выравниваем: 4,20 + 1,35.
```
  4,20
+ 1,35
------
  5,55
```
420 + 135 = 555, значит 4,2 + 1,35 = 5,55.

## Вычитание десятичных дробей

Пример: 8,3 − 2,45.
```
  8,30
− 2,45
------
  5,85
```
Дописали 0 к 8,3 → 8,30. Вычитаем: 830 − 245 = 585, значит 8,3 − 2,45 = 5,85.

Пример: 6 − 2,4. Целое число 6 записывают как 6,0.
```
  6,0
− 2,4
-----
  3,6
```
60 − 24 = 36, значит 6 − 2,4 = 3,6.

## Сложение и вычитание нескольких чисел

Правило то же самое: выравнивают запятые у всех чисел сразу и выполняют действия по порядку.

Пример: 1,5 + 2,25 − 0,75. Сначала 1,5 + 2,25 = 3,75 (1,50+2,25). Затем 3,75 − 0,75 = 3,00 = 3.

## Мини-практика

1. Сложи 4,2 + 1,35 — выравниваем запятую (4,20+1,35), **5,55**.
2. Вычти 6 − 2,4 — **3,6** (6,0 − 2,4 = 3,6).
3. Сложи 3,45 + 2,7 — **6,15** (3,45+2,70).
4. Вычти 8,3 − 2,45 — **5,85** (8,30−2,45).
5. Сложи 0,9 + 0,45 — **1,35** (0,90+0,45).
6. Вычти 5 − 1,25 — **3,75** (5,00−1,25).
