# Past Simple: неправильные глаголы (список)

## Слова по теме

| Английский | Перевод |
|---|---|
| go — went | идти/ехать — пошёл/поехал |
| see — saw | видеть — увидел |
| have — had | иметь — имел |
| do — did | делать — сделал |
| eat — ate | есть — съел |
| buy — bought | покупать — купил |
| write — wrote | писать — написал |
| read — read | читать — прочитал |
| take — took | брать — взял |
| come — came | приходить — пришёл |
| get — got | получать — получил |
| give — gave | давать — дал |

Примеры:
- I **saw** a great film. (Я посмотрел отличный фильм.)
- She **wrote** a letter. (Она написала письмо.)
- We **had** breakfast at 8. (Мы позавтракали в 8.)

## Мини-практика

1. Впиши прошедшую форму глагола go — **went**.
2. Впиши прошедшую форму глагола write — **wrote**.
3. Впиши прошедшую форму глагола buy — **bought**.
4. Переведи слово took — **взял**.
5. Впиши прошедшую форму глагола eat — **ate**.
6. Переведи слово came — **пришёл**.
