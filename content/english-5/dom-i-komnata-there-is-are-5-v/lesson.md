# Дом и комната: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| house | дом |
| flat | квартира |
| room | комната |
| bedroom | спальня |
| kitchen | кухня |
| bathroom | ванная |
| living room | гостиная |
| window | окно |
| door | дверь |
| wall | стена |
| floor | пол / этаж |
| garden | сад |

Примеры:
- My **house** has got a **garden**. (У моего дома есть сад.)
- The **kitchen** is next to the **living room**. (Кухня рядом с гостиной.)
- Look at the **window** and the **door**. (Посмотри на окно и дверь.)

## Мини-практика

1. Переведи слово garden — **сад**.
2. Как по-английски «спальня»? — **bedroom**.
3. Переведи слово bathroom — **ванная**.
4. Как по-английски «гостиная»? — **living room**.
5. Переведи слово wall — **стена**.
6. Переведи слово floor — **пол / этаж**.
