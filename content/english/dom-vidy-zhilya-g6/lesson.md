# Дом: there is / there are

## Грамматика: there is / there are

Используем, чтобы сказать, что где-то что-то есть (существует). **There is** — с
единственным числом (и неисчисляемыми), **there are** — со множественным числом.

- **There is** a sofa in the living room. (В гостиной есть диван.)
- **There are** two bedrooms in our flat. (В нашей квартире две спальни.)
- **There isn't** a garage near our house. (Рядом с нашим домом нет гаража.)
- **Are there** any shelves in your room? (В твоей комнате есть полки?)

Отрицание: **there isn't** / **there aren't**. Вопрос: **is there...?** / **are there...?**

Краткий ответ: **Yes, there is. / No, there isn't.** (для единственного числа), **Yes,
there are. / No, there aren't.** (для множественного числа).

## Мини-практика

1. Как сказать «в кухне есть стол»? — **There is a table in the kitchen** (стол — единственное число).
2. Впиши: ___ there any lamps in the bedroom? — **Are** (lamps — множественное число).
3. Составь отрицание: в саду нет гаража — **There isn't a garage in the garden**.
4. Ответь кратко на вопрос «Is there a sofa in the room?», если диван есть — **Yes, there is.**
