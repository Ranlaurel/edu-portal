# Выдающиеся люди: наука и искусство (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| scientist | учёный |
| artist | художник |
| invent | изобретать |
| discover | открывать (делать открытие) |
| paint | рисовать (красками) |
| compose | сочинять (музыку) |
| composer | композитор |
| painting | картина |
| invention | изобретение |
| discovery | открытие |
| famous | знаменитый |
| talented | талантливый |
| achievement | достижение |
| create | создавать |
| genius | гений |

## Мини-практика

1. Переведи слово invention — **изобретение**.
2. Переведи слово discovery — **открытие**.
3. Как будет «сочинять музыку» на английском? — **compose**.
4. Переведи слово achievement — **достижение**.
5. Чем invent отличается от discover? — **invent — изобретать (создавать новое), discover — открывать (находить то, что уже существовало)**.
6. Переведи слово genius — **гений**.
