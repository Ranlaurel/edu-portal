# Задачи на углы треугольника

## Углы, заданные через отношение или разность
В задачах углы треугольника часто заданы не числами, а соотношением друг с другом. Тогда сумму 180° делят на части.
Пример: углы треугольника относятся как 1:2:3. Всего частей: 1 + 2 + 3 = 6. Одна часть: 180° ÷ 6 = 30°. Углы равны: 30°, 60°, 90°.
Пример: один угол в 2 раза больше другого, а третий равен 30°. Пусть меньший угол — x, тогда больший — 2x. x + 2x + 30° = 180°, 3x = 150°, x = **50°**. Углы: 50°, 100°, 30°.
Пример: один угол на 20° больше второго, третий равен 70°. Пусть меньший угол — x, больший — x + 20°. x + (x + 20°) + 70° = 180°, 2x = 90°, x = **45°**. Углы: 45°, 65°, 70°.

## Внешний угол треугольника
Внешний угол треугольника равен сумме двух внутренних углов, не смежных с ним. Он также равен 180° минус смежный с ним внутренний угол.
Пример: внутренние углы треугольника 40° и 60°. Внешний угол при третьей вершине: 40° + 60° = **100°** (и проверка: 180° − 80° = 100°, так как третий внутренний угол 180° − 40° − 60° = 80°).
Пример: внешний угол при вершине треугольника равен 130°. Смежный с ним внутренний угол: 180° − 130° = **50°**.

## Мини-практика
1. Углы треугольника относятся как 2:3:4. Найди углы — **40°, 60°, 80°** (180° ÷ 9 = 20°, части 2×20=40, 3×20=60, 4×20=80).
2. Один угол в 3 раза больше другого, третий угол 20°. Найди углы — **40° и 120°** (x + 3x + 20° = 180°, 4x = 160°, x = 40°, 3x = 120°).
3. Один угол на 10° больше второго, третий равен 90°. Найди меньший угол — **40°** (x + x + 10° + 90° = 180°, 2x = 80°, x = 40°).
4. Внутренние углы треугольника 55° и 65°. Найди внешний угол при третьей вершине — **120°** (55° + 65° = 120°).
5. Внешний угол треугольника равен 110°. Найди смежный внутренний угол — **70°** (180° − 110° = 70°).
6. Углы треугольника относятся как 1:1:2. Найди углы — **45°, 45°, 90°** (180° ÷ 4 = 45°, части 45, 45, 90).
