# Профессии и планы на будущее (слова)

## Слова по теме

| Английский | Перевод |
|---|---|
| profession / job | профессия |
| doctor | врач |
| teacher | учитель |
| engineer | инженер |
| pilot | пилот |
| lawyer | юрист |
| chef | повар |
| firefighter | пожарный |
| police officer | полицейский |
| scientist | учёный |
| artist | художник |
| singer | певец |
| programmer | программист |
| vet | ветеринар |
| businessman / businesswoman | бизнесмен / бизнесвумен |

## Примеры предложений

- My uncle is a **firefighter**, and my aunt is a **lawyer**. (Мой дядя пожарный, а
моя тётя юрист.)
- She wants to become a **vet** because she loves animals. (Она хочет стать
ветеринаром, потому что любит животных.)
- A good **chef** knows a lot about food. (Хороший повар много знает о еде.)

## Мини-практика

1. Переведи слово scientist — **учёный**.
2. Как будет «повар» на английском? — **chef**.
3. Переведи firefighter — **пожарный**.
4. Как по-английски «полицейский»? — **police officer**.
5. Переведи слово businessman — **бизнесмен**.
