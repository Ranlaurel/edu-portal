# Сложение и вычитание дробей с одинаковыми знаменателями

## Сложение дробей с одинаковыми знаменателями
Чтобы сложить дроби с одинаковым знаменателем, нужно сложить их числители, а знаменатель оставить без изменения.
Пример: 2/7 + 3/7 = (2 + 3)/7 = **5/7**.
Пример: 1/5 + 2/5 = (1 + 2)/5 = **3/5**.

## Вычитание дробей с одинаковыми знаменателями
Чтобы вычесть дроби с одинаковым знаменателем, нужно вычесть числители, а знаменатель оставить без изменения.
Пример: 5/8 − 2/8 = (5 − 2)/8 = **3/8**.
Пример: 7/9 − 4/9 = (7 − 4)/9 = **3/9**.

## Когда получается неправильная дробь или единица
Если сумма числителей равна знаменателю, получается 1.
Пример: 3/5 + 2/5 = 5/5 = **1**.
Если сумма числителей больше знаменателя, получается неправильная дробь — её можно оставить так или позже превратить в смешанное число.
Пример: 4/6 + 3/6 = 7/6 (неправильная дробь, больше 1).

## Почему знаменатель не меняется
Знаменатель показывает размер долей, на которые разделено целое. Когда складывают или вычитают дроби с одинаковым знаменателем, доли остаются того же размера — меняется только количество взятых долей (числитель).
Пример: если целое разделено на 7 частей, то 2 части да ещё 3 части — это 5 частей из тех же семи, то есть 5/7.

## Мини-практика
1. Вычисли 3/10 + 4/10 — **7/10** ((3 + 4)/10 = 7/10).
2. Вычисли 6/7 − 2/7 — **4/7** ((6 − 2)/7 = 4/7).
3. Вычисли 2/9 + 7/9 — **1** ((2 + 7)/9 = 9/9 = 1).
4. Вычисли 5/6 − 1/6 — **4/6** ((5 − 1)/6 = 4/6).
5. Вычисли 3/8 + 3/8 — **6/8** ((3 + 3)/8 = 6/8).
6. Вычисли 9/11 − 5/11 — **4/11** ((9 − 5)/11 = 4/11).
