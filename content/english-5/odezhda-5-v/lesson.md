# Одежда: слова

## Слова по теме

| Английский | Перевод |
|---|---|
| clothes | одежда |
| T-shirt | футболка |
| trousers | брюки |
| jeans | джинсы |
| dress | платье |
| skirt | юбка |
| shoes | туфли (обувь) |
| socks | носки |
| jacket | куртка |
| hat | шапка |
| coat | пальто |
| wear | носить (одежду) |

Примеры:
- My **jacket** is warm. (Моя куртка тёплая.)
- I like this **dress**. (Мне нравится это платье.)
- Put on your **shoes** and **socks**. (Надень туфли и носки.)

## Мини-практика

1. Переведи слово skirt — **юбка**.
2. Как по-английски «носки»? — **socks**.
3. Переведи слово coat — **пальто**.
4. Как по-английски «куртка»? — **jacket**.
5. Переведи слово trousers — **брюки**.
6. Переведи слово wear — **носить**.
