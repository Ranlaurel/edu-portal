# Задание 9. Уравнения

В задании 9 нужно решить уравнение и записать корень. Если корней несколько, в условии сказано, какой записать — **больший** или **меньший**. Прочитай это до того, как вписывать ответ.

## Линейные уравнения
Переносим неизвестные в одну сторону, числа — в другую, меняя знак при переносе.
- 6x − 5 = 2x + 7 → 6x − 2x = 7 + 5 → 4x = 12 → **x = 3**.
- Скобки раскрываем сразу: 3(x − 2) = x + 4 → 3x − 6 = x + 4 → 2x = 10 → **x = 5**.
- С дробями умножаем обе части на общий знаменатель: (x + 1)/2 = (x + 5)/3 → 3(x + 1) = 2(x + 5) → **x = 7**.

## Квадратные уравнения
Уравнение ax² + bx + c = 0 решаем через дискриминант: **D = b² − 4ac**.
- D > 0 — два корня: x = (−b ± √D) / (2a).
- D = 0 — один корень: x = −b / (2a).
- D < 0 — корней нет.

Пример: x² − 5x + 6 = 0, D = 25 − 24 = 1, x = (5 ± 1)/2, корни **2** и **3**.

## Неполные квадратные уравнения
Решаются без дискриминанта:
- x² − 5x = 0 → x(x − 5) = 0 → **x = 0** или **x = 5**.
- x² − 16 = 0 → x² = 16 → **x = ±4**.
- x² + 4 = 0 → x² = −4 → **корней нет**.

## Частые ловушки
- Уравнение не приведено к виду ax² + bx + c = 0: x² = 2x + 8 сначала переписываем как x² − 2x − 8 = 0.
- Записали меньший корень вместо большего.
- Ошиблись в знаке при переносе слагаемого.

## Мини-практика
1. 0,5x + 4 = 2,5 — **x = −3**.
2. x² − 2x − 8 = 0, меньший корень — **−2** (корни −2 и 4).
3. x² + 2x + 3 = 0 — **корней нет** (D = −8).
4. x² + 3x = 0 — **−3 и 0**.
