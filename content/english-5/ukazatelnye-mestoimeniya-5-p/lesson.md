# These/those: множественное число

## Слова по теме

| Английский | Перевод |
|---|---|
| window | окно |
| picture | картинка |
| shoes | туфли |
| flowers | цветы |

## Грамматика: these/those

Для множественного числа: **these** (эти) — предметы рядом, **those** (те) — предметы далеко.

|  | близко (здесь) | далеко (там) |
|---|---|---|
| единственное число | this | that |
| множественное число | **these** | **those** |

- **These** shoes are new. (**Эти** туфли новые — рядом.)
- **Those** flowers are beautiful. (**Те** цветы красивые — далеко.)

## Мини-практика

1. Как сказать «те цветы» (далеко, мн. число)? — **those flowers**.
2. Впиши местоимение: ___ shoes are new (туфли рядом, мн. число). — **these**.
3. Переведи слово window — **окно**.
4. Как будет «картинка» на английском? — **picture**.
