# Дом: слова по теме

## Слова по теме

| Английский | Перевод |
|---|---|
| house | дом |
| flat / apartment | квартира |
| room | комната |
| living room | гостиная |
| bedroom | спальня |
| kitchen | кухня |
| bathroom | ванная |
| garden | сад |
| garage | гараж |
| stairs | лестница |
| furniture | мебель |
| sofa / couch | диван |
| wardrobe | шкаф |
| shelf | полка |
| lamp | лампа |

## Примеры предложений

- Our **flat** has three **rooms**. (В нашей квартире три комнаты.)
- I like sitting on the **sofa** in the **living room**. (Мне нравится сидеть на диване в гостиной.)
- My clothes are in the **wardrobe**. (Моя одежда в шкафу.)
- We keep the car in the **garage**. (Мы держим машину в гараже.)

## Мини-практика

1. Переведи слово wardrobe — **шкаф**.
2. Как будет «лестница» на английском? — **stairs**.
3. Переведи слово furniture — **мебель**.
4. Как по-английски «ванная»? — **bathroom**.
5. Переведи предложение: There is a lamp on the shelf. — **На полке стоит лампа.**
